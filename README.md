# 一起拼图 · 可玩原型

本机 / 局域网的拼图社区原型：首页采用「午后纸艺馆」暖米白纸艺主题，按用户选定参考的左图呈现完整纸艺场景。拖拼块开门或点击/跳过后进入随机开局页，无需登录即可开始或继续单人拼图，进度保存在当前浏览器。公开大厅位于 /lobby，点开卡片即可作为游客一起拼；个人空间、创建房间与用时榜也无需登录。/account 保留可选账号入口，当前没有付费会员。二十张可玩图片与首屏场景均为本项目通过内置 image_gen 生成，游玩无需第三方图片服务。

## 已实现

- 首页还原参考左图的左侧文案、嵌套拼图拱门、柠檬海岸画与前景弯曲胶片。使用无文字的生成布景，品牌、标题、按钮均为真实 HTML；场景和可拖动拼块轻微视差，进入时镜头向画中推进。拖拼块到缺口或普通按钮触发过场，跳过直接选图，减少动态效果时直接切换。窄屏文案与场景上下排列；流程不等待账号请求。素材与提示词记录见 content/image-provenance/hero-paper-coast-v2.json。
- 首屏后的轮播已取消，片数菜单旁提供随机开局：从完整在架图库等概率抽一张并立即开始；去图库仍可手选。开局同步防重入，冻结图片、片数与房间范围。全部未完成的本机存档提供继续入口，包括已归档作品。
- 完整图库位于 /gallery，包含全部二十张图片及分类、搜索；首页不再放分类和搜索。图库图片卡片直接开局，个人空间进入图库会保留独自拼图或创建房间模式。
- 选图、游玩、登录注册、公开大厅和用时榜统一纸艺配色；图片本身不滤色，片数菜单保留暖色毛玻璃。原有开场素材与来源记录保留，不重新用于当前首屏。
- 本地账号注册、密码登录、退出登录。注册字段持续提示账号 3–24 位英文、数字或下划线，昵称 1–16 个字符，密码 8–128 个字符及相应格式要求。账号/昵称/密码摘要保存在本地数据库，独立随机盐 + PBKDF2，Cookie 为 HttpOnly/SameSite，服务器只保存随机会话凭证摘要；登录失败 8 次后限制 15 分钟。没有外部登录或邮件服务。
- 顶部提供中文 / EN 切换，覆盖开场、选图、房间、公开大厅、个人空间、用时榜与账号表单；本浏览器记住偏好，多标签同步。切换不会重建拼图或重新连接房间，自定义昵称与图片 ID 不被翻译；图片支持中英文名称搜索。
- 公开大厅采用响应式平铺卡片，整卡点击进入，无需先注册或填写昵称。每张图叠加真实人数 N/8、每秒更新的计时、片数和状态；满员禁用，等待开拼时为 00:00。八张生成图各有一张预设公开桌，完成或过期后补充新桌。私人房间和单人局不进入公开目录。
- 游客凭本浏览器的随机身份使用服务器房间，Cookie 为 HttpOnly/SameSite，首次多标签进入通过浏览器数据库事务协调身份。同一身份计为一位玩家，保留最多八张近期身份绑定票据，避免同时加入互相挤掉连接；游客随后选择登录仍能继续原游客个人局，并在「我的桌面」看到两种身份的房间。清除浏览器站点数据后无法恢复游客个人局的所有权。
- 个人空间先选「独自拼图」或「创建房间」，再使用随机开局或进入图库手选及片数菜单；创建时可选私人邀请或公开到大厅。新单人局也由本地服务器保存，可从「我的桌面」继续；本机存档保留，可从首页直接继续，不计用时榜。
- 用时榜分单人和合作，游客也可查看，按相同图片、片数与参与人数筛选。第一次合法拿起拼块开始计时，全部归位后冻结；暂停/离线不会暂停榜单计时。实际操作过拼块的账号或游客身份去重计为参与者，旁观者不计入合作人数；成绩按房间唯一保存，完成弹窗可直达对应榜单。私人房间成绩仅返回摘要结果编号，不公开可加入的邀请 ID。

- 二十张在架图片（十张保留图加十张简洁新图），首页随机开局，图库展示全部；新开局提供 108 / 300 / 500 / 1000 / 1500 / 2000 片，单人和多人使用相同档位。
- 片数菜单保留暖色毛玻璃。2000 片使用 50×40 网格、5:4 画幅，主体为正方形；原图居中等比裁切，参考图和完成预览保持一致。12、48、3000、4000、5000 片的旧存档及房间保留，可继续或查看历史成绩；首页提供旧存档的继续入口。
- 不规则拼块；互补边形；桌面外相邻拼块吸附成组；整组拖动与归位。
- 桌面缩放/平移、双指缩放、边缘组筛选、单人整理散片；共享桌面保持其他玩家的布局。
- 游玩界面底部工具栏提供月亮/太阳背景按钮，切换米色与炭灰暗色。当前浏览器记住选择并同步同源标签页；每位玩家独立选择，不发送到房间，不重建游戏或改变进度、镜头、图片纹理。暗色同时调整底板、网格、文字及工具颜色。
- 提示、原图、底图均锁定，点击只显示规则。后续提示每局每人最多 3 次，每次观看广告获得一次提示；原图次数不限，每次完整广告解锁 30 秒，到期收起；底图每次广告解锁 30 秒。当前未接广告，没有模拟观看或临时解锁。
- 吸附距离统一为拼块短边的 26%（原 18%），单人鼠标、键盘和多人一致；只吸附真正相邻的拼块，保留抢块保护。
- 300 片以上预先裁切纹理、只绘制可见拼块，并缓存拖动时的静止桌面；2000 片可放大至 640%；旧 3000 片仍可放大至 800%。放大超出缓存分辨率后直接采样原图像素并绘制矢量轮廓，原图不再限制到 2400 像素宽。相邻拼块查找及存档连通性验证使用四邻域索引。
- 放大时按实际屏幕像素密度决定是否使用拼块纹理缓存；高像素密度屏幕不再因倍率低于 250% 而继续放大较小缓存。达到缓存原生尺寸后立即直接采样原图，普通缩放与拖动仍复用缓存。
- 在架 20 张：保留 10 张旧作，新增 10 张简洁插画；新增原生尺寸均为 1402×1122，未放大。归档 10 张密集画面只用于既有存档、房间和历史成绩，不再用于新开局。所有游玩 WebP 保持原尺寸、逐像素无损；列表使用 480 像素以内的 WebP 缩略图，均离线预编码并按内容哈希缓存。高倍放大仍受原生细节限制。
- 暂停操作、可选吸附音效、完成反馈。账号局由服务器保存，首页单人局独立保存在浏览器；只有本机单人计时随暂停停止。
- 单人 / 多人完成后自动居中展示整幅拼图，播放约 3.5 秒「拼块盛典」：三层拼块彩纸、金箔、卷曲金色彩带分三波喷出，金色粉末带着柔和光晕漂浮在画面前方，结束后显示成绩。同一次游玩不会因多人轮询重复触发，成绩面板支持再次庆祝。
- 完成后仍可再次预览庆祝；未完成的游玩页隐藏庆祝预览，避免展示完整原图绕过锁定。粒子使用独立 Canvas，桌面为 1200 个彩纸 / 彩带粒子加 1800 粒金粉，窄屏为 620 加 850 粒；结束、关闭或离开页面会清理动画资源。系统选择「减少动态效果」时跳过粒子并显示完成结果。
- 键盘：桌面获得焦点后 N 选下一块，方向键移动，Shift 微调，Enter 吸附，0 适应桌面。

最多 8 人同时在线，支持邀请、共享进度、抢块保护和重连；房间有效期 24 小时。当前没有上传、真实广告、邮件找回密码或公网账号服务。

## 运行与验证

### 本地 / 局域网试玩（无需互联网）

双击项目里的 `启动本地拼图.cmd`，或运行 `npm run local`。启动程序使用已经安装的依赖完成本地构建、初始化本地数据库，再启动服务器，不会发布网站或连接远程数据库。

- 本机打开 `http://localhost:3000`，点击开场的进入按钮或跳过后，选图与片数即可开始单人拼图。多人合作使用顶部公开大厅，创建房间使用个人空间；这些入口和用时榜均无需注册或登录。可选账号页可随时返回游玩。
- 房间内会显示这台电脑的局域网邀请地址；同一路由器 / Wi-Fi 的朋友直接在浏览器中打开。即使房主使用 localhost，邀请也会自动使用局域网地址。
- 同一浏览器的窗口共享游客身份或登录账号，只计为同一个玩家；多人测试用另一台设备、另一个浏览器或独立无痕会话即可，无需账号。局域网 HTTP 页面不能自动复制时，链接会选中，按 Ctrl+C 或长按复制。
- 保留启动窗口；Ctrl+C 停止。之后双击同一文件重新启动，原来的本地房间和进度仍可用（房间创建后 24 小时有效）。
- 房间数据存放在 `.wrangler/state/v3/d1`。本地与公网房间分别保存；要本地玩，请新建本地房间。图片随项目保存，不需要外部图片或字体服务。
- 路由器无需接入互联网，但多人设备必须互通；没有局域网地址时只支持本机窗口。局域网地址随网卡配置自动选取，换网络后重新启动再复制邀请。
- Windows 防火墙需允许专用网络的 TCP 3000 端口；当前电脑已为本项目配置仅限本地子网的入站规则。

依赖已随当前工作区安装。复制到另一台尚未安装 Node.js 或依赖的电脑时，需先准备运行环境，启动脚本不会自动联网下载。

`npm install`、`npm run dev`；部署构建为 `npm run build`。

`node --experimental-strip-types --test tests/puzzle-engine.test.mjs` 验证互补边形、初始布局、正确/错误吸附、整组移动与归位、边缘显示、整理、存档校验，以及全部档位（最高 2000 片）的完成和存档恢复。

`node node_modules/typescript/bin/tsc --noEmit` 检查类型。

WebMCP 通过特性检测注册 `read_puzzle_session` / `start_puzzle_session`。本环境未提供可验证 WebMCP 调用的上下文，此集成未做运行验证；不影响普通浏览器游玩。本轮按环境规则未执行浏览器操作测试。

## 图片来源

当前在架 20 张均为本项目通过内置 image_gen 生成，未使用外部参考图片。新增十张的提示词与原件记录在 content/image-prompts、content/image-provenance，生成批次原件与完整记录在 ../artwork/simple-gallery-20260909。原生尺寸 1402×1122；实际分辨率和展示压缩分别记录。早期柠檬海岸提示词未保留，来源记录明确说明。

`content/puzzle-catalog.json` 区分 published 与 archived；前者可开新局，后者仅保留已开始的游戏。早期外部示例 skate/gold/red 仍被禁止，不属于可恢复名单。不会用新画面覆盖任何旧图片 ID。

`python scripts/prepare-image-delivery.py` 用 Pillow 离线编码缩略图和无损游戏图，验证游戏图解码后的每个像素与 PNG 一致。`npm run check:images` 同时校验原件、衍生 WebP、原生尺寸、文件哈希、提示词和来源；构建时自动执行。原件不删除，列表不加载原件，游玩不使用缩略图。依据生成服务输出条款记录使用来源；视觉检查和 AI 生成不等于独占权或不侵权的绝对保证。

本轮变更及加载体积见 [简洁图库与随机开局](docs/2026-09-09-random-gallery.md)。

## 多人合作实现与验证

- 公开桌面在首页直接加入，选图与自主创建统一进入个人空间；游玩中不再放另一个创建入口。
- 使用本项目 D1 绑定 PUZZLE_DB；版本条件更新防止并发覆盖；拖动租约 10 秒，移动及持有心跳续期，未持有的连接心跳不会延长失去的租约。
- 拿起即开始本地拖动，服务器后台确认占用；移动只保留最新位置，同一时刻最多一个移动请求，发送间隔至少 60 ms。放下优先于尚未发送的移动，等待确认时可先拖其他组；服务器拒绝占用时恢复共享位置。
- 客户端在上次请求完成约 300 ms 后拉取共享状态，持有心跳独立续期；只在状态变化时重绘或更新工具栏。网络延迟仍会影响其他玩家看到移动的速度。
- 各玩家持有独立的房间令牌，服务器只存摘要；邀请地址含随机房间 ID，已知邀请地址可申请加入；房间快照不含令牌或摘要。
- 局部工具（原图、筛选、提示、缩放、暂停）各自独立；多人暂停只暂停自己的操作。多人桌面不提供整体重新整理或重开，避免覆盖其他玩家的工作。
- `node --import ./tests/ts-register.mjs --test tests/*.test.mjs` 包含引擎、真实 HTTP 双客户端、实际轮询客户端，以及模拟 500 ms 网络延迟、立即拖动与连续拖放测试。HTTP 测试默认使用 localhost:3001，可通过 PUZZLE_TEST_URL 指定测试入口。
- `celebration.test.mjs` 验证完成只触发一次、相同轨迹不依赖帧率、粒子数量上限、前景层、播放结束回调、重播资源清理、减少动态效果与页面切后台的处理。动画为本地 Canvas 绘制，无需外部特效服务。
- `puzzle-picture.test.mjs` 验证各档位正方形主体、准确片数、旧进度迁移、原图等比裁切与边缘采样；`large-puzzle.test.mjs` 验证高倍缩放直接使用原图而非小尺寸纹理缓存。
- 验证包括引擎、注册登录和注销、限流、跨来源拒绝、账号/游客绑定、私人/单人隔离、公开目录、完成用时与去重，以及最高 2000 片拖动；未进行浏览器视觉或交互操作测试。guest-http.test.mjs 额外验证游客直入、同身份并发加入、可选登录后继续原个人局和私人成绩脱敏；language.test.mjs 验证翻译、语言订阅与状态保留。
- 账号和游客 HTTP 测试分别在 work/community-test-cleanup.sql、work/guest-test-cleanup.sql 中记录本次创建的账号和房间的精确清理语句；验收后只按这些 ID 清理测试数据，预设空桌保留。
- 登录与大厅设计见 [本地公开大厅改版](docs/2026-09-08-public-lobby-design.md)，开场三层原图、实际提示词及来源记录见 [开场素材记录](docs/intro-assets.md)。新增数据库迁移为 drizzle/0001_lobby_accounts.sql，启动脚本幂等应用本地迁移。
- 在本地服务器上设置 `PUZZLE_TEST_URL=http://localhost:3000`、`PUZZLE_TEST_LOCAL=1`、`PUZZLE_TEST_LARGE=1` 后运行全套测试，可同时验证本机与局域网邀请，以及真实 2000 片双人房间。`large-puzzle.test.mjs` 另验证绘制缓存、画面裁剪、放大上限及更宽松的吸附。
- 本地数据库初始化：`node node_modules/wrangler/bin/wrangler.js d1 execute PUZZLE_DB --local --config wrangler.local.json --file drizzle/0000_puzzle_rooms.sql`。正式部署由 Sites 应用归档中的迁移。
- 网站整体访问权限仍由 Sites 控制；网站私有时，同账号两个窗口可测试，多账号朋友需先获得网站访问权限。
