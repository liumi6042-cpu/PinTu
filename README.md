# 一起拼图 · 可玩原型

保留胶片转轮选图方向，重点验证单人拼图过程。图片均在本站提供，游玩无需第三方图片服务。

## 已实现

- 四张图片、搜索与分类，12 / 48 / 108 / 300 / 500 / 1000 / 1500 / 2000 / 3000 / 4000 / 5000 片；单人和多人使用相同档位。
- 不规则拼块；互补边形；桌面外相邻拼块吸附成组；整组拖动与归位。
- 桌面缩放/平移、双指缩放、原图、边缘组筛选、位置提示、整理散片。
- 底图已锁定，点击入口只显示说明。后续广告规则为「完整观看一次广告，解锁 30 秒底图，到期收起」；当前未接广告，也没有临时解锁入口。
- 吸附距离统一为拼块短边的 26%（原 18%），单人鼠标、键盘和多人一致；只吸附真正相邻的拼块，保留抢块保护。
- 300 片以上预先裁切纹理、只绘制可见拼块，并缓存拖动时的静止桌面；5000 片可放大至 1200%。相邻拼块查找及存档连通性验证使用四邻域索引。
- 暂停计时、可选吸附音效、完成反馈。每张图每种片数分别保存在本浏览器，刷新续玩。
- 单人 / 多人完成后自动居中展示整幅拼图，播放约 3.5 秒「拼块盛典」：三层拼块彩纸、金箔、卷曲金色彩带分三波喷出，金色粉末带着柔和光晕漂浮在画面前方，结束后显示成绩。同一次游玩不会因多人轮询重复触发，成绩面板支持再次庆祝。
- 选图页和游玩页底栏均有「预览庆祝」，可直接试玩、反复重播，不改变拼块位置或完成进度。粒子使用独立 Canvas，桌面为 1200 个彩纸 / 彩带粒子加 1800 粒金粉，窄屏为 620 加 850 粒；图片精灵和金粉光晕复用缓存，金粉统一批量绘制；结束、关闭或离开页面会清理动画资源。系统选择「减少动态效果」时跳过粒子并显示完成结果。
- 键盘：桌面获得焦点后 N 选下一块，方向键移动，Shift 微调，Enter 吸附，0 适应桌面。

现已加入多人合作试玩：最多 8 人、创建与邀请房间、共享拼块与进度、抢块保护、刷新重连；房间有效期 24 小时。单人存档仍独立保存在本浏览器。暂不含账号系统、上传或广告。

## 运行与验证

### 本地 / 局域网试玩（无需互联网）

双击项目里的 `启动本地拼图.cmd`，或运行 `npm run local`。启动程序使用已经安装的依赖完成本地构建、初始化本地数据库，再启动服务器，不会发布网站或连接远程数据库。

- 本机打开 `http://localhost:3000`，选择图片后点击「局域网一起拼」创建房间。
- 房间内会显示这台电脑的局域网邀请地址；同一路由器 / Wi-Fi 的朋友直接在浏览器中打开。即使房主使用 localhost，邀请也会自动使用局域网地址。
- 本机可点「打开第二个窗口」输入另一个昵称测试；局域网 HTTP 页面不能自动复制时，链接会选中，按 Ctrl+C 或长按复制。
- 保留启动窗口；Ctrl+C 停止。之后双击同一文件重新启动，原来的本地房间和进度仍可用（房间创建后 24 小时有效）。
- 房间数据存放在 `.wrangler/state/v3/d1`。本地与公网房间分别保存；要本地玩，请新建本地房间。图片随项目保存，不需要外部图片或字体服务。
- 路由器无需接入互联网，但多人设备必须互通；没有局域网地址时只支持本机窗口。局域网地址随网卡配置自动选取，换网络后重新启动再复制邀请。
- Windows 防火墙需允许专用网络的 TCP 3000 端口；当前电脑已为本项目配置仅限本地子网的入站规则。

依赖已随当前工作区安装。复制到另一台尚未安装 Node.js 或依赖的电脑时，需先准备运行环境，启动脚本不会自动联网下载。

`npm install`、`npm run dev`；部署构建为 `npm run build`。

`node --experimental-strip-types --test tests/puzzle-engine.test.mjs` 验证互补边形、初始布局、正确/错误吸附、整组移动与归位、边缘显示、整理、存档校验，以及全部档位（最高 5000 片）的完成和存档恢复。

`node node_modules/typescript/bin/tsc --noEmit` 检查类型。

WebMCP 通过特性检测注册 `read_puzzle_session` / `start_puzzle_session`。本环境未提供可验证 WebMCP 调用的上下文，此集成未做运行验证；不影响普通浏览器游玩。本轮按环境规则未执行浏览器操作测试。

## 多人合作实现与验证

- 从选图页「和朋友一起拼」创建房间，输入昵称后进入；游玩中的单人桌面底栏也有同一入口。
- 使用本项目 D1 绑定 PUZZLE_DB；版本条件更新防止并发覆盖；拖动租约 10 秒，移动及持有心跳续期，未持有的连接心跳不会延长失去的租约。
- 拿起即开始本地拖动，服务器后台确认占用；移动只保留最新位置，同一时刻最多一个移动请求，发送间隔至少 60 ms。放下优先于尚未发送的移动，等待确认时可先拖其他组；服务器拒绝占用时恢复共享位置。
- 客户端在上次请求完成约 300 ms 后拉取共享状态，持有心跳独立续期；只在状态变化时重绘或更新工具栏。网络延迟仍会影响其他玩家看到移动的速度。
- 各玩家持有独立的房间令牌，服务器只存摘要；邀请地址含随机房间 ID，已知邀请地址可申请加入；房间快照不含令牌或摘要。
- 局部工具（原图、筛选、提示、缩放、暂停）各自独立；多人暂停只暂停自己的操作。多人桌面不提供整体重新整理或重开，避免覆盖其他玩家的工作。
- `node --import ./tests/ts-register.mjs --test tests/*.test.mjs` 包含引擎、真实 HTTP 双客户端、实际轮询客户端，以及模拟 500 ms 网络延迟、立即拖动与连续拖放测试。HTTP 测试默认使用 localhost:3001，可通过 PUZZLE_TEST_URL 指定测试入口。
- `celebration.test.mjs` 验证完成只触发一次、相同轨迹不依赖帧率、粒子数量上限、前景层、播放结束回调、重播资源清理、减少动态效果与页面切后台的处理。动画为本地 Canvas 绘制，无需外部特效服务。
- 在本地服务器上设置 `PUZZLE_TEST_URL=http://localhost:3000`、`PUZZLE_TEST_LOCAL=1`、`PUZZLE_TEST_LARGE=1` 后运行全套测试，可同时验证本机与局域网邀请，以及真实 5000 片双人房间。`large-puzzle.test.mjs` 另验证绘制缓存、画面裁剪、放大上限及更宽松的吸附。
- 本地数据库初始化：`node node_modules/wrangler/bin/wrangler.js d1 execute PUZZLE_DB --local --config wrangler.local.json --file drizzle/0000_puzzle_rooms.sql`。正式部署由 Sites 应用归档中的迁移。
- 网站整体访问权限仍由 Sites 控制；网站私有时，同账号两个窗口可测试，多账号朋友需先获得网站访问权限。
