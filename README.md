# 拼图相册工作台

本地项目位于 `D:/chat/拼图/content-admin`，入口为 [相册工作台](http://127.0.0.1:3214/)。用相册统一整理图片：每个相册就是一个图鉴；开启「购买包」后，同一个相册也作为收费图包。PC 与小程序共用一套相册，只在相册设置中选择在哪一端显示。

## 启动与登录

需要本机现有 Node.js 24，无需安装依赖。运行 `start.ps1`，再打开本地入口；也可在本目录运行 `npm start`。`stop.ps1` 只停止本工具记录的后台进程。

已有管理员继续使用原账号登录。首次访问才需要创建独立内容管理员，用户名 2–40 字符，密码 10–128 字符；没有默认密码或公开注册。内容管理员与游戏玩家账号独立，本版不提供邮件找回。

## 平时怎么用

只维护一份「当前工作内容」，日常整理不需要选择、创建或切换草稿。主界面只有两个入口：

| 页签 | 用途 |
| --- | --- |
| 相册与未分配 | 同屏查看相册和未分配图片，直接拖动分配；点击相册进入内部图片查看与整理 |
| 全部图片 | 查看所有素材，按画风和题材筛选、编辑标签、选择图片放入相册 |

在「相册与未分配」页，把未分配图片拖到目标相册卡片，即可加入相册；也可先多选，再拖动其中一张，把所选图片一起放入。电脑宽屏采用左右排列，窄屏相册固定在图片上方。无法方便拖动时，继续使用多选后的「放入相册」按钮。顶部不再切换 PC 或小程序内容。

点击相册卡片进入内部图片页，查看成员、调整顺序、加入或移出图片。每张图片只能属于一个相册；加入另一相册时会移动原归属。名称、封面、成员、顺序、购买价格和奖励共用，整理一次就同时更新两端的内容规划。

相册卡片上的「设置」打开独立弹窗，不影响当前图片浏览位置。弹窗集中控制以下设置：

- **名称、说明与画风**：整理相册基本信息，已有名称会保留。
- **在 PC 显示、在小程序显示**：两项独立勾选。都勾选则两端显示，只勾选一项则只在对应端显示，都不勾选则两端隐藏。
- **购买包**：关闭时为免费相册，价格为 0；开启时设置至少 1 金币的整数价格。
- **封面**：从相册成员中选择；相册成员和图片顺序也是图鉴的成员和顺序。
- **高级奖励**：保留原奖励配置，按需要展开编辑；涉及玩家权益的变动在游戏接入检查中提示。

未分配到相册的图片仍可在后台查看和打标签，默认不纳入普通图库与相册图鉴规划。移出相册会取消共用归属，原件与稳定图片 ID 保留。隐藏相册中的图片仍属于原相册，不会重新出现在「未分配」中。每日专用图片继续使用已有每日拼图入口和选图规则。

画风作为主分组，题材作为图片标签；两者用于查找和整理。多选图片后，底部操作栏可放入相册、移出相册，以及批量设置画风或题材标签。拖动和弹窗修改也使用同一个顶部「保存」按钮；完成整理后点击「保存」。

## 保存与游戏生效

**保存会更新后台的当前工作内容，不会自动部署游戏。** 相册的两端显示选项和购买设置先保存为完整规划，游戏完成配置接入并实际发布后，玩家端才按这些设置使用内容。用户准备让 Web 使用小程序这套前端，本轮先统一相册管理，尚未替换游戏前端。

现有 187 张图片都可在后台整理。2026-10-12 已整理为 10 个相册，未分配为 0，明细见 [图片相册整理记录](docs/2026-10-12-图片相册整理.md)。其中 53 张新图仍标记「待接入游戏」，可分配到相册、选择封面、设置显示和购买；这些操作不会把尚未接入的图片直接送进现有游戏。旧归档图片重新放入可见相册时，也需要检查重新接入的审核与历史兼容。

主界面不再分别维护图包与图鉴，也没有单张图片的上架或图库显隐开关。图包、图鉴和普通图库归属统一从相册规划推导。

## 更多：历史、完整备份与更新文件

顶部「更多 → 历史与备份」保留高级操作。以前的草稿副本作为只读历史查看，日常继续操作当前内容即可。

可检查已保存改动、保存共用相册的完整内容备份，或下载历史备份。恢复备份会成为当前工作内容，不要求再选另一份草稿。保存完整备份、恢复和来源同步需要填写原因并再次验证管理员密码。

「准备更新文件」供后续游戏接入使用，可选择要交付的应用；这里选择的是文件接收方，不是另一套可编辑内容。只有所选应用兼容检查通过时才可生成；有待解决的问题仍可保存整理结果和完整备份。PC 旧运行时尚需接入共用相册规则，检查会明确提示并阻止生成不兼容的更新文件。更新文件包含明确路径的内容文件集合，由原游戏发布流程审阅、接入和发布。文件生成不会替换游戏源码或上线。

来源同步会合并当前整理与原项目的独立改动；同一字段同时被修改时保留编辑并报告冲突，避免静默覆盖。

## 数据保管与验证

后台只读两个游戏项目，写入保存在自身 `work/` 私有目录。目录含管理员密码摘要、会话、当前内容、备份与审计，已忽略版本控制，不能放进公开静态资源目录。停止后台后复制整个 `work/` 可保留完整本地数据；运行期间不要随意替换 SQLite 文件及 WAL。内容备份恢复不涉及玩家数据库。

生成游戏更新文件时复用已有来源、审核、原件、WebP 交付与资源清单校验，不输出原件、密钥、数据库或玩家档案。历史图片 ID、已购权益、奖励、每日轮转与旧房间资源仍受保护。

聚焦检查使用 `npm test`；测试采用独立临时后台，不写真实游戏或正式管理数据。此前相册模型已通过 19 项聚焦验证。当前方案见 [PC 与小程序共用相册记录](docs/2026-10-12-PC小程序共用相册.md)。历史演进见 [相册工作台记录](docs/2026-10-12-相册工作台.md)、[相册拖动整理记录](docs/2026-10-12-相册拖动整理.md)；新图保管记录见 [新图导入记录](docs/2026-10-12-new-art-import.md)。
