# 拼图内容管理后台

本地工程：D:/chat/拼图/content-admin。用于统一查看和整理素材，分别规划 PC 主题画册与共用小游戏的图包、图鉴。微信、TapTap 使用同一小游戏目标；3213 是小游戏预览，本后台使用 3214。

## 启动

需要本机现有 Node.js 24，无需安装依赖。运行 start.ps1 后打开 http://127.0.0.1:3214。也可在本目录运行 npm start（关闭终端会停止前台运行的后台）。stop.ps1 只停止本工具记录的进程。

首次访问创建内容管理员（名称 2–40 字符，密码 10–128 字符）。没有默认密码或公开注册。此管理员与游戏玩家/原网站管理员账号独立，请保管密码；本版不提供邮件找回。

## 使用

1. 选择或创建内容草稿。素材库支持按画风、题材、来源、审核状态、方向与目标状态筛选，单张或批量整理画风/题材标签。素材开始均为“待分类”，不推断图片画风。
2. 切换 PC / 共用小游戏目标，编辑图包或图鉴。封面、图片顺序、金币价格、上下架和奖励均可先规划；历史 ID 保持稳定。
3. 保存草稿后进入发布页，检查前后差异与阻断原因。规划快照能保存完整计划；目标有兼容阻断时不能生成运行候选。生成版本和从版本恢复均需填写原因并再次验证密码。
4. 历史版本可私有下载或恢复成新草稿，不覆盖其他草稿。若其他会话修改了原项目，重新导入会以原导入基线、当前草稿和最新来源合并；相同字段同时修改时拒绝静默覆盖。

## 交付边界

后台只读两个游戏项目，所有写入限于自身 work/admin.sqlite。导出的 JSON 候选包含明确路径的内容文件集合，不会直接替换游戏源码或上线。画风/题材侧边配置仅供管理，游戏采用这些新分组需要后续适配；封面、图包上下架、独立图鉴和旧权益重组的运行时限制会在发布检查中显示。

旧图包成员、价格、奖励、已购权益、每日轮转和旧房间资源受保护。旧图片不删除或重映射。尚未迁移玩家数据、重写房间/奖励后端、开通 CDN 或部署外部网站。

候选生成复用现有来源/原件/交付校验与小游戏资源清单，输出不包含原件、密钥、数据库或玩家档案。新增图片仍应按已有审核/压缩流程进入原项目，本版素材页面先管理已登记素材；不提供绕过审核的直接图片上传。

## 数据保管与验证

work/ 含管理员密码摘要、会话、草稿、版本和审计，已忽略版本控制，不能放进公开静态资源目录。完整备份应在停止后台后复制整个 work/，保留原位置可恢复；SQLite 文件及 WAL 运行期间不能随意替换。本版版本回退恢复的是内容规划，不是玩家数据库。
