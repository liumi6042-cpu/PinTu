# 雨云江苏宿迁京东云 NAT：小程序接口选型

日期：2026-10-21，北京时间。仅调研，未购买或迁移。Chrome 连接连续超时，未读到用户当前套餐、价格、规格；以下依据公开官方资料，不能代表选中套餐验收。

结论：技术上 NAT 可以作为小程序 API 后端，但“只接小程序”不等于无需公网 HTTPS、域名或备案。公网高位端口必须映射到服务，证书覆盖客户端访问域名。若以七牛为入口，需要另行配置支持端口的回源；现有 IP443 回源不能原样用于 NAT。

官方已确认：
- 雨云服务器IP文档：江苏宿迁/重庆支持 NAT共享IP，公网可用端口10000–60000，最多10条映射。不能直接占用公网80/443。
- 微信支付官方文档“小程序场景开发配置”：HTTPS服务、合法服务器域名、ICP备案；支持显式配置端口，但请求端口必须匹配后台配置。因此不能笼统说微信小程序只能443，也不能使用裸公网IP代替合法域名。
- 雨云备案页面公开检索摘要：国内域名HTTP/HTTPS服务需备案；江苏宿迁暂无法在该区域申请备案。已有备案是否适用，以及该具体套餐的API/CDN回源过白要求，购买前仍需雨云确认。

接法：
1. 微信请求直连 https://已备案域名:映射端口/api，前提平台相应请求类型支持该端口且完成合法域名配置；公网IP对应雨云NAT出口。
2. 小程序 → 已备案HTTPS入口/CDN443 → NAT公网IP:映射端口 → API；需要CDN支持该回源端口、动态请求不缓存和方法/认证头透传。使用CDN不会取消源站服务商备案/过白要求。

建议：满足已有域名备案、宿迁允许接口服务、映射端口稳定后，可优先短期试用/月付；不因低价直接长期购买。没有备案且需新办时，优先选支持办理备案的区域。当前七牛域名海外覆盖，不能据此承诺国内玩家直连国内低延迟；跨境回源可能抵消宿迁优势。

边界：以上具体微信规则仅针对微信小程序；TapTap H5/其他平台应查各自接入要求。尚未确认用户本次“小程序”具体平台，也未验证特定套餐的性能、延迟、流量或价格。
