## B2 概念图图标对齐 — icons23（2026-10-11）

以上 V3–V10、preview09 条目为历史素材记录。本轮以已确认的 B2 浅色概念图为参考，使用内置 `image_gen` 重新生成透明彩色图标，并与原生单色操作符号配套。

- `b2-core-icons23.png`：16 枚基础彩色图标，4×4 独立格子。
- `b2-task-icons23.png`：8 枚任务与奖励彩色插画；与基础图集合计 24 枚彩图。
- 17 枚单色操作剪影由代码绘制，沿用文字颜色或按钮前景色；它们与透明 PNG 插画分开管理，不把嵌入位图当作矢量图标。
- `b2-icons23-generation.json`：保存生成提示词、参考图、实际源尺寸与格子边界元数据。显示坐标使用这份记录，不假定新图集尺寸与旧素材一致。
- 彩图作为独立小图源按格子取用，保留透明背景；单个图标随现有容器等比显示，不承担可伸缩按钮、面板或选择器边框。边框仍使用 `public/pixel-ui` 原生像素系统。
- 接入时保留 picker22 的布局、无高光和阴影的平面选择器，以及已有圆润两端、细高光的进度条。补给站两幅大场景继续使用 `b2-supply-scenes.png`。
- 验收：TypeScript、82 张图库检查、3 项移动画布测试及 H5 构建通过；构建保留原有非阻断配置/分包警告。16 个 390/320/844 屏幕状态无溢出、坏图或页面异常，并人工查看大厅、任务、补给、装饰、游戏与工具。结果见 [icons23 验收记录](../../docs/verification/2026-10-11-b2-icons23/README.md)。仅本地预览：[打开 icons23](http://127.0.0.1:3211/?v=b2-icons23#/zh/lobby)，未上传 TapTap。
