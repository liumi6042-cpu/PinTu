# 图库与点击开局更新

选图页保留八张精选胶片，搜索和分类移动到 `/gallery`。取消下拉纸签、抽出过场及惊喜抽取入口；先选片数，点击图片或开始按钮直接游玩。首屏的拼块开门和视差场景保留。

图库包含全部二十张原图，以卡片平铺，支持中文/EN、分类和搜索。从个人空间进入图库时保留单人计时或创建房间的模式，公开/私人范围在开局前选择；普通图库默认进入当前浏览器保存的免登录单人局。

新开局档位为 108、300、500、1000、1500、2000。2000 片采用 50×40 网格、5:4 画幅，原图居中等比裁切，拼块主体保持正方形。新开局 API 和 WebMCP 使用相同限制。

旧 12、48、3000、4000、5000 片存档和服务器房间仍可继续、整理、完成和查询历史成绩。恢复与历史榜单使用独立档位表，避免新范围使旧数据失效。首页或图库下方仅在有旧存档时显示继续入口。

## 图片与清晰度

本次新增十二张原创生成图：灯火夜市、郁金香风车、秋庭茶舍、晨光面包房、雨林百鸟、林溪伙伴、釉彩工坊、星辉观测台、浮岛飞瀑、彩屋港湾、花园野餐、雪国灯火。实际提示词保存在 `content/image-prompts`，逐图尺寸、原件位置、摘要和检查记录保存在 `content/image-provenance`。

生成通过内置 image_gen 完成，没有外部参考图。提示词要求更高原生分辨率，但工具实际返回 1448×1086；不把请求的 4096×3072 标成实际尺寸，不插值放大原件，也不以原生 4K 宣传。已有八张原图及图片 ID 保留，避免更换画面破坏存档。

目前图片源像素不足是高倍率模糊的主要原因：2000 片时，1448×1086 原图每片约 27×27 源像素，1774×887 原图约 22×22。桌面已有原生像素采样，放大时不会持续放大小纹理缓存；本次另外开启缓存缩小时的高质量平滑，但这不能创造缺失的细节。取得更高原生分辨率的生成结果后才能进一步改善。

账号与房间数据仍只存在本机服务器，没有部署公网，也没有启用广告或付费会员。
