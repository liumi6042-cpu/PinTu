# Jigsaw Nook 网站图标

2026-09-12 制作。沿用午后纸艺馆的陶土色 `#ac6246` 和米白色 `#fbf6eb`，主体是一块拼图，拱门负形呼应首页。为小尺寸识别省略文字、细线和纹理。

本项目直接绘制的 SVG，无外部素材或字体；`public/favicon.svg` 是可编辑源文件。离线运行 `node scripts/prepare-site-icons.mjs`（使用构建机已安装的 sharp）导出：

- `favicon.ico`：16、32、48 像素独立 PNG 帧。
- `favicon-96.png`：96 像素浏览器及搜索图标。
- `apple-touch-icon.png`：180 像素手机收藏图标，实色铺底，由系统处理外形。

根布局声明图标类型及尺寸，用 `paper-arch-1` 查询版本刷新旧标签图标缓存。所有必需图标列入运行包白名单；矢量源本身也是网站运行资源。图标生成脚本不进入服务器，也不在网页请求中转换图片。
