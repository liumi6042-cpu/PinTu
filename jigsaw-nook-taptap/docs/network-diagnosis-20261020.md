## 测量边界与排错说明

- 本机 DNS 返回 `198.18.78.62` Fake-IP，说明普通域名请求经过代理或网关。指定源站 IP 且 `--noproxy` 只能绕过 DNS/CDN 和显式代理，无法证明绕过透明代理；不能当作所有国内玩家的直连成绩。
- 服务器独立访问域名也测得 SJC / SEA 节点与约 1 秒接口耗时，支持 Cloudflare 路由存在额外延迟，但不代表玩家一定落到相同节点。
- 最初裸访问 `127.0.0.1:3104` 得到 503，原因是现有中间件校验公开 origin；补齐正式 Host、X-Forwarded-Proto、X-Forwarded-Host 后均为 200。这不是线上故障。
- Windows 指定源站 IP 的首轮请求遇到证书吊销检查服务器不可达；后续仅对诊断请求使用 `--ssl-revoke-best-effort` 处理离线吊销查询，仍保留证书主机名及信任链校验，没有改系统 TLS 设置。
- 服务器到公共 DNS 的各 5 次 ICMP 均无丢包，但公共 DNS 可能为 anycast；不用于推断中国玩家线路质量。

## 1 TB 可支持的游戏时长预算

用户继续询问可支持多少玩家各玩一小时。本轮只读核查当前线上资源、公共图库响应及同步源码，没有创建测试房、进行压力测试或测量完整一小时会话。

- 当前 Web 配置仍指向 UI `31d12aea1e22cda3`，实时连接协议 version 1。
- 当前公共图库 263 张，实际正图中位数 353,998 字节（约 0.35 MB），90 分位 940,792 字节，最大 1,469,104 字节；缩略图中位数 37,782 字节，90 分位 63,382 字节。全库缩略图合计 10,545,072 字节，但一次打开不等于全部下载。
- 游戏 JS gzip 传输量沿用本轮实测 140,950 字节；当前字体文件 357,584 字节，两项音频共 74,776 字节。UI 图片文件共约 6.08 MB，同样不等于每次全部下载。图片和静态文件可被浏览器缓存，换图、浏览更多图库会增加传输。
- 同步源码为差量拼图更新；光标移动时客户端最高约 15 次/秒，服务端通知会带光标列表，房间人数和实际操作频率影响下行量。数据库光标持久化节流不能等同于广播流量同比下降。故不能仅用一张图大小或挂机心跳推算完整多人游戏流量。

用于采购规划，暂以 **50–100 MB / 玩家小时** 为中间预算档，并预留 **200 MB / 玩家小时** 的多人高频档；这些是显式预算假设，不是已实测的一小时均值，也不是流量上限。

1 TB 资源包按 HTTPS 的 1.15 抵扣系数，约有 0.87 TB 实际下行，即约 90 万 MB。按上述档位，约为：

| 假设每玩家小时下行 | 可支撑的累计玩家小时 |
| --- | --- |
| 50 MB | 18,000 |
| 100 MB | 9,000 |
| 200 MB | 4,500 |

这里计算的是**累计时长**，不是服务器同时在线容量；也以相关图片、脚本和实时流量均实际经过计费的七牛节点为前提。若只接静态资源，资源包只承担该部分，不能拿全站下行预算直接套算。实际采购应先用小规模真实会话的计费字节除以玩家小时校准，并把动态请求费用单独计算。
