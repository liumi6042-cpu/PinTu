# 拼图主循环与花园留存首批上线

用户已批准梳理、实现、测试后上线。范围为每日一起拼、完成纪念卡、主题画册、伙伴续局及七日贡献规则；神秘拼图、画中发现、15×15 区域扩建不在本批。

1. 大厅沿用全站统一每日选图（北京时间零点更新）。今日一起拼优先找到该图可加入且未完成的公开桌，优先有人的桌；没有时创建 300 片公开桌。
2. 拼合操作与贡献算法不变。完成后沿用庆祝动画，完整画作淡入，展示本人有效拼合次数、贡献比例和参与伙伴。玩家主动保存 PNG 纪念卡，不自动下载。
3. 服务器纪念册为默认页。灯火里的奇遇包括猫咪市集、舞会、魔法树屋；已有真实完成记录可点亮，三张集齐显示印章。完成当天推荐图获得日期印章，无连续要求。参与者来自永久完成结果，用户上传原图不对外公开或进入主题。
4. 公开桌有实际贡献的伙伴可在三个固定候选中每人投一票，允许改选。任一伙伴点准备后冻结最高票，平票按候选顺序，创建共同的 300 片公开桌。该旧桌只有一个后继房间；并发、重试不创建多桌。其他伙伴自行选择加入，未操作的人保留在完成画面。
5. 七日花园礼保留七款与已配置数量。单局 300 片及以上贡献至少 50%，或同一 UTC 日期已完成的大拼图累计 100 次有效拼合，满足其一达成一天。未完成、重复请求、重复拖动、108片不累计。开始活动前的局不追溯。断日不清零、每天最多一份、活动专属不兑换不孵出。
6. 花园正式账号保存、旧资产一次性折算、种植全周期和新蛋池随本批发布。旧资料快照保留，迁移不清空成就/装扮/孵化进度，发布前在线数据库备份。试玩数据不复制进正式账号。

发布验收：类型检查、贡献/活动/画册单测、真实 HTTP 双人投票与并发开桌、完成后刷新、鉴权、浏览器中英文主要页面、运行包资产及旧版本兼容。使用现有蓝绿部署，保留上一个回退目录，不改正在玩的拼图状态。
