# TapTap H5 紧凑大厅（2026-10-09）

- 独立 H5 大厅改为快捷按钮与房间列表，去掉日拼封面、介绍、片数选择、换图日期，以及大厅统计和重复说明。
- 每日拼图一键请求108片档位；优先加入同图同档可加入房间，否则创建公开房间。共享后端沿用按图片比例生成实际网格的既有规则。
- 接着拼缩为按钮，仍进入原房间；选图、随机、筛选、搜索、广告、账号与语言入口保留。交流群收至底部折叠入口，帮助、隐私和条款入口保留。
- 日拼有同步点击锁、加载状态、失败错误及手动重试。未改原站项目、原后端或数据库。
