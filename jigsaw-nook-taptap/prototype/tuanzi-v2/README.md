# 团子去旅行 2.0 · 绘本风可玩交互原型

面向《拼图小窝 · 拾光物语》移动端新模块的交互式可玩原型，验证：

1. **离线世界持续运行**：基于确定性惰性演进引擎（`engine.js`），支持随行布包、玄关备品篮多日自动续行、无粮自主日常、零惩罚机制。
2. **回访惊喜**：旅拍明信片「记忆显影」3×3 轻拼图、拾光镇居民与动物旅伴连续剧来信（折纸 2 选 1 轻回信）、窗台小鱼干与风铃交互。
3. **三层记忆收藏**：跨季照片对照、带时光附记的风物来历铭牌、拾光人生切片与水彩角色圆章羁绊。
4. **行前准备轻策略**：奶奶的旧布包三槽化学反应（口粮 × 器物 × 心愿信物）+ 玄关备品篮 + 窗台招待碟 + 轻推小门即时送行。
5. **长期变化与动态表现**：
   - 真实公历四季流转（10 月初秋午后 → 11 月初冬雪夜）；
   - 窗格精准裁切 Canvas 天气粒子（初冬飘雪 / 雨巷细雨 / 春樱微风 / 夏夜萤火 / 秋日晴风）+ 久别手势拂尘金尘；
   - 活态团子多态动效（打盹呼吸、摸摸蹭手与爪印粒子、坐起待发、小碎步出门告别、归来重逢）。

## 本地运行与测试

```bash
# 运行离线世界演进单元测试
node --test jigsaw-nook-taptap/prototype/tuanzi-v2/engine.test.mjs

# 启动零依赖本地原型服务器（默认 http://127.0.0.1:4178/）
node jigsaw-nook-taptap/prototype/tuanzi-v2/serve.mjs
```
