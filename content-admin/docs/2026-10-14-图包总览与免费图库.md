# 图包总览与免费图库

状态：2026-10-15 已部署 Web 与小程序后端；微信客户端未上传。相册、任务、成长配置保持不变。见 [上线记录](2026-10-15-收藏页面上线.md)。下方保留开发与本地预览说明。

## 用户规则

- 图包点击后先打开全部图片缩略图总览，电脑四列、手机两列；缩略图区独立滚动，底部解锁入口固定。
- 点击缩略图才打开大图；返回总览保留滚动位置。大图内按 Escape 返回总览，再按 Escape 关闭窗口。
- 免费图库来自当前平台可见的免费相册，零金币相册也算免费。同图同时属于免费和收费相册时优先免费。
- 隐藏、未分配、只在另一平台显示及尚未正式收录的每日首发图片不混入免费图库。
- 已购图片保留原权益；每日图片单独可玩的规则保持。

## 实现位置

- `jigsaw-nook-taptap/mobile/app.ts`：共享 Canvas 总览窗口；消费明确的 `freeImageIds`，免费标签不再叫“随机免费”。
- `jigsaw-nook-taptap/server/mobile-collection.mjs`、`server/mobile-service.mjs`：小游戏/本地预览的免费相册分类。
- `work/dual-managed-release-20261014/lib/shared-client-api.ts`、`lib/managed-economy.ts`、`lib/shared-client-model.ts`：正式 Web 后端分类修复。原接口错误地把可使用图片集合作为 `packedImageIds`，已纠正；“我的图包”仅使用实际购买权益，不再混入免费相册图片。
- 未编辑原始 `puzzle-play` 项目。

## 图片压缩核对

当前登记的 187 张图片均已有缩略 WebP、无损 WebP、优化 WebP。导入脚本自动生成交付图，用户无需手工压缩；原图保留，已生成文件会校验复用，不反复重编码。

后台目前没有上传原图即时处理入口。后台“保存”和“提交到双端”更新内容配置，不会生成或上传图片；新图仍经导入/图片交付流程处理。
