# 本地公开大厅与游玩入口改版

用户已确定新增公开多人大厅、独立个人入口、按用时排名、广告工具锁定，以及超现实分层穿越开场；登录选择本地账号注册与密码登录。

## 页面与行为

- 首次访问：独立远中近景视差开场，点击进入播放约 1.4 秒镜头推进，随后进入登录/注册。提供跳过动画；减少动态效果时直接切换。已登录回访默认公开大厅。邀请深链接登录后回到原房间。
- 主导航：公开大厅、个人空间、用时榜。公开大厅显示真实房间人数、片数、已完成比例和状态；登录后点房间直接加入。预设四桌在完成/过期后补充新桌，空桌显示 0 人，不伪造玩家。
- 个人空间先选择独自拼图或创建房间，再进入胶片选图与片数选择。新单人局也由本地服务器保存，用于统一计时和用时榜；原浏览器旧单人存档保留，可另行继续但不计新榜。私人房间不出现在公开大厅，用户创建时可选择公开。
- 用时榜分单人和合作，按同图片、同片数、同参与人数比较；时间从第一次合法拿起拼块开始至全部归位，由服务器记录，暂停/离线不中断排名计时。参与者按实际拿起过拼块的账号去重；不提交客户端自报分数，不虚构榜单条目。
- 提示、原图、底图当前全部锁住，没有模拟广告或临时解锁。未来提示每局每人最多 3 次；原图次数不限，每次完整广告解锁 30 秒；底图每次广告解锁 30 秒。游玩中的庆祝预览不能绕过原图锁，完成后的展示和庆祝保留。

## 本地账号与数据

- 账号为 3–24 位英文字母、数字或下划线，展示昵称 1–16 字，密码 8–128 字。密码保存带独立盐的派生摘要，登录凭证为随机不透明 HttpOnly/SameSite Cookie，服务器只保存令牌摘要。登录失败有持久化限流。注销使当前令牌失效。
- 本地 D1 增加用户、会话、登录限流、房间目录和完成记录表，保留原房间表和存档。公开房间也只在当前本机/局域网可访问，不发布到互联网。
- 房间操作延续现有令牌、抢块租约和版本条件更新。新注册房间绑定账号；私人邀请不出现在目录中，单人局只允许创建者重新加入。旧匿名邀请接口保留兼容，但不录入新榜。
- 完成记录按房间唯一写入，合作并发完成不会重复记分。目录只返回摘要，不能暴露房间令牌、密码、会话或成员私有身份字段。

## 实施与验收

先实现账号、目录和成绩存储，再接入开场/认证/大厅/个人空间/榜单以及工具锁；原生拼图引擎与拖动渲染继续复用。新增纯函数与真实本地 HTTP 验证涵盖注册登录/注销/鉴权、公开与私人隔离、一键加入与单人所有权、排名计时和重复完成、广告锁定；现有拼图、5000 片和多人拖动测试继续通过。最后构建并重启本地服务供用户试玩。
