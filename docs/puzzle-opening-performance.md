# 拼图开局加载（2026-09-13）

108–2000 片采用同一原尺寸无损 WebP。片数少不会减小图片请求；当前在架图片约 1.3–2.93 MB。现场客户端网络取样中，Winter Village 的 2,600,400 字节图片首次 CDN MISS 为 8.751 秒，随后 HIT 为 4.947 秒；健康请求在源站本机为约 41 毫秒，服务器负载很低。这些是这次网络取样，不是所有玩家的加载时间或浏览器完整开局耗时。

此前公开房间串行等待页面、浏览器脚本、游客身份、入房快照，然后才开始图片下载。重新打开已有有效房间凭证时也必定先请求 `/api/guest`。

本次调整：

- 公开房间初始 HTML 直接声明唯一原图 preload，图片下载与脚本/入房请求重叠。只有未过期 public 房间中的公开图库资源可提前声明；私人、solo、自上传、关闭、未知和过期房间不输出该资源提示。
- 点选大厅房间或图库图片立即预载当前所选的原图，使用客户端导航保持下载和已加载脚本。大厅 `Link` 禁用自动路由预取；不扫图库预载、不同时下载整批原图。客户端复用最多一个图片提示节点。
- 有旧凭证时先由服务器验证原 Cookie 与票据；成功即使用此快照。只有 401 时恢复持久游客 Cookie 并重试原票据；新玩家仍先建立稳定身份再入座，所有权限判断仍由原接口执行。
- 游玩图片使用高加载优先级及异步解码提示，退出清除回调。音效、拼块像素、原尺寸/无损编码、进度、吸附和拖动逻辑不变。

测试覆盖资源提示范围、单个提示复用、有效票据单请求、Cookie 恢复、首次入座与拒绝访问。发行包另以独立数据库验证实际公开/私人页面 preload 和身份访问。前端性能回归沿用画布拖动及拼合反馈测试。早期 `room-client.test.mjs` 需要旧的本地 3001/Wrangler 测试服务，本次该服务未启动；不将这项连接失败记为通过，改由隔离 Node HTTP 验证开局接口。

限制：首次访问仍需实际下载完整无损图，海外链路速度及设备准备拼块的速度仍影响等待；不承诺秒开，也不以低清缩略图替代游玩图片。原服务器/CDN 一年 immutable 缓存已验证生效，无需修改基础设施或增加跟踪请求。
