# B2 浅莓奶油界面实施记录

日期：2026-10-10
范围：独立 TapTap 手机版，本地预览。未部署线上、未上传 TapTap。
批准依据：用户确认 B2 浅色概念，并要求“开始落实概念图效果，尽量一比一还原”。

## 页面与素材

- 大厅：像素头像/等级/体力、任务和补给入口；每日108档、收藏；方向和片数筛选、快速加入与建房；竖屏双列、横屏自适应房卡。
- 图库：48/108/300/500档，方向、分类、搜索，免费图库/我的图包/全部，已拥有图包权益提示与紧凑建房区。
- 游戏：B2 两行竖屏标题栏与单行横屏标题栏、真实名字/等级/装饰光标、左下任务、右下折叠工具、拼合反馈。
- 常规玩法仍为自由画布。托盘默认关闭，从“更多”主动打开；点击托盘仅定位真实拼块，不改房间同步坐标。
- 首次进房按真实散片分布打开局部视野，碎片主体至少44 CSS px。旋转保留视角；双指缩放和平移，“适配”查看全桌。
- 任务/礼包、补给、图鉴、主题图包、装饰和完图结算统一 B2 配色与像素素材。
- 使用本地 OFL 字体子集，保留 public/fonts/FONT-NOTICES.md 和许可证。
- 新图标：public/mobile-icons/b2-pixel-atlas.png；生成记录与提示词保存于同目录 b2-pixel-atlas.json。功能按钮使用SVG，不把整页概念图当界面。
- 概念以实际界面参考保留在 docs/concepts/2026-10-10-b2-full-ui。不再新增概念介绍网页。

## 收藏系统的可调初始值

用户确认收集循环及已购图包权益；以下数值是本地首版调参值，不表示最终运营定价。

| 事件/项目 | 当前值 |
| --- | --- |
| 服务器确认本人有效拼合 | 1金币；原体力/经验/十格/合作任务继续结算 |
| 房间完成额外金币 | ceil(个人贡献 × 0.5) |
| 完图碎片 | min(10, max(1, floor(个人贡献/10)))；零贡献无奖励 |
| 点亮图鉴 | 本轮完成且个人有效贡献至少3次；分别记录难度档 |
| 主题图包 | 云端奇遇、花间灯火、山水漫游，各6张、180金币 |
| 图鉴册奖励 | 3张额外30金币；6张额外60金币及专属装饰，自动发放 |
| 普通装饰配方 | 奶油蝴蝶结30、蜜糖流星45、玫瑰蝶影60、薄荷羽毛60碎片 |
| 默认装饰 | 免费拥有并装备莓色星光，可更换/卸下 |

数值和图片归类集中于 lib/mobile-collection-catalog.json。18张组成主题包，其余61张为基础池，保留图片ID与现有作品。已购图片指定公开建房免券；其他指定/私房沿用新手首免与建房券规则，仍最多3个未完成自建房。加入他人的公开房无需买图包。

新身份从零金币和碎片开始；不把概念图示例余额写入玩家账号。既有已完成房间不追溯补发。离线贡献者可在房间完成后获得奖励。

## 数据与工程边界

- 原 PC 项目 puzzle-play 未改动，房间和成长库继续独立。
- 预览数据仍在 data/mobile-v3-preview；新增收藏表使用现有独立 SQLite、有效贡献来源与事务。
- 购买/合成、有效拼合、完成奖励与里程碑做幂等处理；购买和合成支持请求重试。异常一起回滚体力、拼图与收藏写入。
- 当前沿用已有访客身份；没有新增跨设备账号恢复或支付会员。
- 普通浏览器用于体验拼图；真实广告需在 TapTap 运行环境验证。没有用模拟广告伪装奖励。
- 当前构建使用 /h5 与 /，只适用于本地或同域服务预览。releases 中本轮生成的 ZIP 不是已上传的测试版本。
