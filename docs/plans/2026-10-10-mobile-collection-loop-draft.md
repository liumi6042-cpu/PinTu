# 手机版收集循环讨论稿

日期：2026-10-10
状态：2026-10-10用户已确认本收集方向及推荐图包权益，并要求按B2浅色版生成各界面概念图。用户随后批准按概念图开发，已接入本地首版；当前可调数值见 [实施记录](2026-10-10-b2-implementation.md)。下文保留策划讨论过程。

## 用户提出的循环

完成拼图 → 获得金币、图鉴进度、任务进度、碎片 → 金币购买普通图包、碎片合成鼠标装饰 → 集齐图鉴领取金币与装饰 → 新图片、新装饰、新难度 → 继续拼图。

已确认视觉基准沿用 B2「莓红奶油·浅色」。用户本轮确认收集方向后，要求先统一生成各界面概念图；后续按确认稿实施功能和视觉。

## 建议的核心体验

把每次真实参与留下的积累，与完成作品后的仪式感结合。基础积累不全部绑在房间完图时，避免参与很久但队友离开便没有长期收获。

- 本人有效拼合：继续按现有规则结算体力、经验、十格和协作任务；另外累计基础金币收益。
- 房间完成：按个人贡献结算额外金币与装饰碎片，并更新符合参与条件的个人图鉴。
- 中途离开保留已赚取收益。房间后来完成时，满足条件的贡献者仍结算奖励，不要求在线或抢到最后一片。房间最终未完成则没有完成奖金，但保留基础收益。
- 同一轮次与玩家只能结算一次。复用当前有效操作口径，不能把已连接组中的旧进度再次记作新贡献。

## 第一阶段只增加两种可消耗资源

| 项目 | 用途 | 建议规则 |
|---|---|---|
| 金币 | 购买固定内容的主题图包 | 展示图包预览和明确价格；永久解锁权益，不重复买同一包 |
| 装饰碎片 | 合成指定拼图装饰 | 初期只用一种通用材料；明确配方进度，可选择目标 |
| 图鉴 | 保存作品收藏和主题完成度 | 它是收藏进度，不是第三种货币 |
| 任务进度 | 提供短期目标 | 接入现有任务面板，不另设重复的一套任务入口 |

金币、装饰碎片初期专用于收藏，不额外兑换体力；装饰不提高金币、经验或体力收益。保留已有广告补给、十格礼包与邀请奖励规则，避免本轮同时改动全部经济系统。

奖励及价格暂不写死。先选择目标：新玩家较快买到第一包、能看到第一件装饰的明确进度，同时后续收藏仍有积累空间。实际数值以有效操作量和贡献占比校准，不根据房间在线人数或最后一片发奖。

## 图包与建房券的权益（2026-10-10已确认）

已确认采用以下权益方向：
- 拥有图包后，免费指定该包内的图片创建公开房间。
- 未拥有的图片可继续用建房券作单次体验，单次体验不自动永久获得图包。
- 私人房间继续沿用建房券规则。
- 同时最多三个未结束自建房的限制继续有效。
- 加入他人的公开房间保持开放，不因为未购买图包而阻断合作。
- 可以从他人的房间获得符合条件的图鉴进度；个人图包所有权与作品参与收藏分别展示。
- 随机免费建房从基础免费图库及本人已拥有图包抽取；新增主题内容和基础图库如何归类需另定。
- 不在讨论阶段回收已有权益或修改正在运行的房间。

用户以“可以的，按你说的来”确认推荐方向：已购图包免费指定公开建房；私人房间继续用券，同时最多3个未结束自建房。当前已在独立手机版本地预览实施，原 PC 与线上版本不变。

## 图鉴和重复游玩

- 以主题分册，例如云海幻想、花间小径、山水旅行。每册可先按 6～8 张组织，此为规模建议。
- 单张先灰色/轮廓预览，达成有效参与条件且房间完成后点亮。
- 最低有效参与条件需要另定。按自身真实贡献判断，不能仅进房围观或只靠抢最后一片点亮。
- 多局同图的个人贡献可以累计作为收藏条件，避免中途加入或合作人数较多的玩家被迫独自完成整图；是否累计及具体门槛仍待确认。
- 例如点亮 3 张给小额金币、集齐整册给明确专属装饰；阶段数值均是示意。
- 同图重复拼仍有基础金币及正常完图收益，首次点亮和整册收藏奖励不重复发。
- 先维持 48 / 108 / 300 / 500 档。不同难度在同一收藏卡上记录徽章，不把同图拆成四张收藏卡。
- 整册基础收集不要求每张反复完成全部四档。高难度可以有额外荣誉章，避免收藏变成强制重复劳动。
- 后续优先增加清楚主题的图片内容。新难度机制另行讨论，不在本轮自动突破手机版500片范围。

## 手机端装饰的可见性

手机没有持续悬停的鼠标。建议产品统一称为「拼图装饰」：
- 首期优先实现小型拖动指示装饰，按住操作时出现，抬手隐藏；同房伙伴可见。
- 在个人展示或名字附近留一个小预览，让玩家知道正在装备什么。
- 控制体积，不遮挡连接边缘、目标位置和触控。
- 后续再评估头像框、拼合特效、聊天气泡等类型，不在首期一次堆满。
- 现有源代码包含 cursor/bubble 资产映射及装备读取基础，但旧权益存储依赖原账号庭院体系，手机版应建立独立的所有权、合成与装备记录，不能直接混用旧账号数据。

## 界面建议

- 大厅新增一个「收藏」入口即可，金币和碎片放在收藏面板内展示，避免顶栏塞满余额。
- 收藏页分图鉴、图包、装饰；复用现有任务入口承载收藏目标。
- 可标记一个当前收集目标，显示还差多少金币或装饰碎片。
- 结算先突出本局作品与个人贡献，再用一行展示金币、材料、图鉴更新；任务进度合并反馈，不连续弹四个窗口。
- 图鉴展示长期作品收藏，不恢复此前删除的流水式拼图记录功能。
- 用户已要求本轮按B2生成各界面概念图；覆盖范围与规则约束见[全界面概念图规格](../concepts/2026-10-10-b2-full-ui/interface-spec.md)。

## 技术方向与第一期范围

继续使用当前独立手游后端，不重写一套后端，也不接回PC房间。
已核对 server/mobile-service.mjs 中个人贡献、完成结算去重与离线贡献者入账基础；金币与合成还未实现。

建议增加可追溯的金币/碎片账本、图包所有权、图鉴进度、合成与装备记录；购买扣款与发权益、合成扣材料与发装饰在同一原子操作中完成。上线前处理稳定玩家身份与账号绑定/恢复方案，避免长期收藏仅依赖容易丢失的本机游客凭证。

首期建议闭环：基础贡献金币 → 完图奖励 → 少量固定主题包 → 图鉴点亮与套装奖 → 通用碎片定向合成 → 装备并展示。
内容量可先用少量主题包和装饰验证节奏；不在首期增加交易、付费抽取、装饰属性、赛季、排行榜或复杂新难度。
