# 高清图库渐进升级与不中断请求的发布

用户批准连续自然风景的四区域重生成拼接方式，要求缩减片数选择、低清图不能新开高片数，并避免影响在线玩家。首批替换山湖倒影、晨光草坡和清澈海湾，图库仍为 30 张。新图用独立 `-hd-v3` ID，旧版转 archived，原来房间/计时/拼块/聊天不换图、不重置。

## 选择体验

六档：108、300、500、1000、2000、5000。默认 300，主动选择保存在 `puzzle:piece-count:v1`，失效旧选项回到 300。桌面六列，手机三列两行，原生单选框支持键盘与焦点。搜索和分类与片数一起筛选；选 2000/5000 后只显示符合要求的图，数量即时显示，无结果可清除筛选或明确改为 300。卡片不重新加入用户已经移除的画面建议。

新建入口统一校验裁切后每块主体原始像素 `min(width/cols,height/rows)`，最低 30；108 片最低 20，以兼容符合上传规则的小图。1774×887 图新建最高 1000；首批 3144×1572 / 3147×1574 图可新建 5000。阈值只是避免过细分割，不能保证任意缩放都清晰。1500/3000/4000 从新建选项退出，但现有局和低清高片数旧局继续正常恢复、加入、整理与同步。随机池与当前片数过滤保持一致，服务器也拒绝绕过前端的新建请求。

## 后续批次

`content/artwork/gallery-hd/upgrade-queue.json` 记录未升级条目。每批最多两张，使用项目生成的构图与四个重叠区域参考；每块通过内置 image_gen 重新生成细节，检查实际尺寸及四块图，再离线曝光匹配、最小差异接缝与窄带融合。输出不插值放大，记录 composite=true 对应信息、nativeResolution=false、finalUpscaling=false。不可把四幅不连续风景直接拼成四格，也不可宣称整张为原生 4K/8K。

先把成图作为本地候选，检查连续构图与接缝，合格后才加入目录。保留真实提示词、工具返回路径、参考原件哈希、四区域原件、合成尺寸、最终 SHA256、所有衍生文件。运行来源校验、片数/存档兼容测试、类型检查及独立运行包验收后再发布；有错误就留在本地，不触碰线上。不要运行旧单实例 restart 部署脚本。

## 双实例发布约束

`scripts/deploy-warm-release.py` 是单独的运维工具，不进入网页运行包。仅上传已经验证且 Git 干净的 latest.tar.gz。工具验证归档哈希、所有运行文件、迁移文件完全相同，先用临时数据库同时启动旧/新代码验证跨版本的旧局续玩，再准备新版本。

生产新实例使用 `jigsaw-web@<port>.service`，在 3103/3104 间轮换，WorkingDirectory 为 `slots/<port>` 链接，端口仅监听回环地址。共享现有数据库、上传图片与备份目录，账号和房间不能复制为新数据库。保持原有 systemd 用户、内存上限、文件访问保护和 nginx 安全/限流配置。新实例健康且 SSR 预热完成后，先保留当前目录全部旧哈希客户端文件，再切换 current 静态资源链接和该站点 upstream，`nginx -t` 后平滑 reload。

旧实例在旧 nginx worker 排空前保持运行；不得强制刷新客户端，不得关闭正在处理的请求。排空后停止旧实例并关闭其自动启动；新实例开机自启。若排空超过等待窗口，保留旧服务并报告待观察，不能超时强杀。备份服务仍基于 current 目录工作，运行顺序不绑定旧服务。切换失败先恢复 nginx 配置及 current 并保持原实例；正式接收新版本创建的房间后，不可盲目用旧客户端目录回退（旧客户端可能不认识新图片）。

nginx 的配置重载和旧 worker 处理完现有请求后退出的行为见 [官方控制文档](https://nginx.org/en/docs/control.html#reconfiguration)。

仅在确认现版及上一回退版健康后删除更早的构建目录和已校验上传临时包。绝不能清理 shared、数据库、上传图片、备份或其他站点。记录当前服务、端口、发布版本与保留的回退版本，作为下一轮的前置核对依据。

## 验收

- 图片来源、区域哈希、尺寸、实际 WebP 无损块、列表资源白名单。
- 六档片数、裁切阈值、旧高片数房间/存档、随机候选、SEO旧图介绍跳转。
- HTTP 新建拒绝低清高片数和已退出档位；5000 种子响应和旧完整快照兼容。
- 旧、新服务对同一临时房间读写和聊天互通，不覆盖棋盘、lease 或计时。
- TypeScript 与独立运行包：30 卡片、6 单选、全部运行图片访问及哈希，原件/私密文件不可访问。
- 线上只读健康与静态访问；不向玩家房间发送测试聊天、创建测试房间或重置进度。
