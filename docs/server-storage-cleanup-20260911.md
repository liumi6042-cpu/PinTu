## 删除与保留范围

- 当前 `20260911-07` 与上一版 `20260911-06` 的重复 `app/public` 副本。删除前逐文件与实际提供服务的 `dist/client` 以及本地原件核对 SHA-256。
- 两版 `dist/client` 中未列入运行资源清单的原始 PNG；所有网页使用的 WebP、缩略图、首屏及 favicon 保留。源文件仍在本地 Git 中。
- 两版构建和运行依赖内的 source maps，以及无人使用的 `shared/npm-cache` 下载缓存。
- 保留当前与一个回退版本、已有 JS/CSS 资源、全部 82 个必需静态图片资源、SQL 迁移、运行依赖与运维配置。
- 共享数据库、会员上传图片、数据库备份和小型历史验收数据库均未删除。原有本地旧压缩包清理限制不属于本次服务器清理。
