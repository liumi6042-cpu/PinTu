# 每日拼图公开配置接入

更新：2026-10-13。新运行采用手动日期 → 未发布自动候选 → 所有相册随机的优先顺序。自动候选没有预留日期，手动新增日期不会挤掉自动图片。

## 启动与配置

后台生成 `jigsaw-daily-content/v2` JSON，默认位于相邻 `content-admin/work/daily-bridge/configuration.json`。`npm run mobile:preview` 在此文件存在时自动接入；显式 `MOBILE_DAILY_CONFIG` 可以覆盖配置路径。服务启动后仍需重启以启用新的接入。没有配置的运行保留原静态每日轮换。

`MOBILE_DAILY_APPEARANCES` 指向独立出场记录目录，默认本项目 `work/daily-appearances`。公开配置与出场记录只交换图片 ID、日期、相册描述、摘要和实际生效事实，不读取管理员数据库，也不包含玩家身份、密钥或密码。外部正式服务仍由既有发布流程更新，不因后台保存自动部署。原 PC 项目保持独立。

v2 配置包含 `entries` 手动计划、`automaticCandidates` 无日期候选、`fallbackImageIds` 相册随机池与 `albums` 相册描述。`configDigest` 使用双方相同的规范化摘要。v1 历史配置及出场记录继续兼容。服务校验配置、摘要与可用素材；非法配置或出场记录不能持久化时明确失败，不临时改为另一张图。

## 选图与出场

服务启动及每 30 秒检查北京时间当天。当天有手动计划时使用它；否则从没有实际出场记录的自动候选中随机选一张；没有未发布候选时，从所有相册可用图片随机选图，包含购买相册与隐藏相册。未分配图片和待接入素材不进入相册随机池，尚未到首发日期的手动图片也不提前作为兜底。

服务仅确认实际当前日期，不补造历史。首个当前日记录以独占文件创建，并锁定当天的图片与预选相册；刷新、重启及未来配置调整不改变已生效日期。v2 出场记录的 `source` 为 `scheduled`、`automatic` 或 `library`；前两种 `planned: true`，相册随机 `planned: false`。

手动或自动首发当天通过每日入口游玩。符合原贡献条件时，当天即可保存完成事实；首发结束后的北京时间次日 00:00，普通图库与图鉴放行至预选相册。相册显隐保持生效。已有相册随机推荐的图片保留原归属，不触发重新搬图。

## 素材与购买权益

每日接入使用已验证的保留素材，包括当前 82 张发布图和 52 张历史归档图。归档资源的普通图库默认行为保持；只有公开配置选中的每日图片按此接入展示。额外 53 张后台新素材尚未交付到游戏，因此只能保留安排，暂不参加实际选图。

每日创建固定为公开房间，绕过图包拥有与建房券要求，仍遵守原房间数量限制。每日免费体验不会获得购买包所有权，普通手选、随机和购买行为继续执行原权限规则。全新购买相册的商店售卖接入是独立事项，不能由一次每日体验授予权益。

`GET /api/daily` 返回服务实际当天图片；`GET /api/mobile/gallery` 返回普通图库可选 ID 和购买图片 ID。前端使用本地保留资源，首发前与首发当天的计划图片不会提前进入普通选图。相册收录沿用同一个图片 ID 与各难度完成事实，重复收据不重复发放金币、碎片或图鉴奖励。

不读取或补写真实旧玩家记录。已经结算的旧每日房间保留原事实，历史图鉴补录需另行提供有效完成证据，不重放奖励。
