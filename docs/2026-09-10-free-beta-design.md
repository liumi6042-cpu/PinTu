# 海外免费限量测试准备

用户已同意 2026-09-10 的七项上线准备建议。此次完成可在现有本地环境验证的免费测试准备；延续本地运行、不发布公网的约束。支付与广告保持未开放，不创建商户、域名或云资源。

## 实施范围

1. 保留 Worker/D1 架构，增加正式环境配置校验、可信来源和响应安全头、数据库健康检查、上线检查报告。正式环境所需域名、经营者、客服、监控/备份验收由检查报告逐项列出，缺失不能报告可上线。
2. 房间写入在单个运行实例内按房间排队，保留数据库版本 CAS 作为跨实例一致性依据；队列有容量限制。客户端对 429/503 遵守 Retry-After；保持本地即时拖动、最终落块确认、占用与序号规则。
3. 增加数据库统一计数的限量测试席位，按已验证身份计数、过期释放，已有席位可续期；不把每桌 8 人和全站测试上限混淆。
4. 在已有账号上增加密码修改、一次性恢复码、恢复密码和删除请求。恢复码仅在生成/轮换时显示，服务器只保留摘要，恢复后撤销全部旧会话。删除请求需要当前密码，提供取消和状态查询；后台人工处理，不声称提交即删除。
5. 增加服务器账号白名单授权的管理页，查看/处理账号删除请求，关闭/重新开放问题房间、屏蔽/恢复异常成绩、冻结/解冻账号。所有变更有操作记录及必填原因。无默认管理员、无公开提权入口。
6. 增加中英文帮助、进度保存说明、隐私/条款草稿和页脚入口。经营主体与联系信息未配置时明确为测试草稿；不虚构经营者、邮箱或已完成法律审查。素材沿用原生尺寸/来源归档，不重新生成图片。
7. 增加多人同时拖动压力测试、弱网/重连回归及浏览器本地验收。真实海外链路、Safari/iOS 真机、长时生产容量不能用模拟测试替代，报告区分已测/待测。

## 验收及外部依赖

保留旧账号、图片、进度与会员规则；迁移仅追加。测试使用独立夹具、按精确 ID 清理；备份当前数据库后才应用迁移。检查 TypeScript、构建、账号恢复和权限 HTTP 测试、多人一致性及请求退避，保留本地服务器。域名、经营主体、客服邮箱、海外部署、异地备份目标及真机设备缺失时继续完成独立工作，并在交付报告中明确未完成项。
