## 字体与视觉校准（2026-10-10，preview02-typography）

用户反馈手机实现的质感弱于概念图，本次仅校准独立手机版表现层。

- 原浏览器实际字体为 Microsoft YaHei UI，标题 800 字重、图片名 600 字重，偏硬且依赖设备字体。正文换为 Noto Sans SC 子集（Jigsaw UI SC），常规 400、图片名 500、按钮 600；页面和设置标题换为 Noto Serif SC 700 子集（Jigsaw Display SC）。操作提示和游戏工具保持清晰的黑体。
- 缩减不必要的粗字，统一行距及数字宽度，卡片添加温和阴影和纸色渐变，按钮与分段控件添加内侧高光。保持现有触控尺寸及页面结构。
- 两款字体采用 SIL OFL 1.1，允许商用、修改及随游戏分发。原授权、版权与来源清单在 public/fonts；生成脚本为 scripts/build-mobile-fonts.py。修改版本使用独立字体家族名并保留原版权、许可字段。
- 字体合计约 360 KB，随包本地加载，不向 Google Fonts 或第三方 CDN 发起字体请求。当前正文子集含 1341 个字符，标题子集含 64 个字符；新文案需重新生成子集，生僻玩家昵称回退到系统字体。
- H5 ZIP 与独立服务器归档均包含 licenses/fonts 下 4 份授权/来源文件；静态服务为 WOFF2 返回 font/woff2。

本轮验证：TypeScript、82 张图库审核、浏览器实际字体/CDP 检查通过；13 项横竖屏布局、11 项补给、14 项游戏交互检查通过；服务包独立解压后核验 645 个文件哈希并创建房间、加载图片。字体文件哈希与来源清单一致，ZIP 中字体与授权齐全。

对比和报告：docs/verification/mobile-typography。新预览仍为 http://127.0.0.1:3211/#/zh/gallery 。本轮未线上部署或上传 TapTap，新版线上路径仍需独立部署后验收。PC 项目状态与改动前一致。
