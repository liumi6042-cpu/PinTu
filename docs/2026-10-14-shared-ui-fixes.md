# 共享客户端入口与拼合反馈修正

用户要求网站仅保留新版游戏界面，补回迁移时遗漏的拼合小特效，并让光标装饰在房间内持续停留。

## 行为

- 新版欢迎提示、失败提示、设置、创建页、我的房间与补给站均取消旧游戏入口。旧大厅、图库、相册等页面直接转入 `/play`，房间链接保留房间与邀请参数。
- 登录注册、账号安全、恢复、会员、协议和反馈服务继续提供；服务页面可返回新版拼图。历史房间与玩家数据保留，当前客户端无法支持的房间显示说明，不再自动打开旧版。
- 共享 Canvas 恢复原来的 500ms 双层暖金轮廓与四颗小亮点，本人和队友反馈强度不同。经验字样只接受服务器实际回执并去重；初始及重连快照不补播，减少动态效果偏好采用短暂静态轮廓。
- Web 回执只读本次落片版本的已结算事件与单笔到账记录。并发打开礼包不会被算入拼合经验；重复或忽略的请求、零经验及尚未结算的落片不显示经验字样。
- 装饰对准鼠标或手指中心，鼠标移出画面和切换窗口后保留最后房间坐标，实际离房时清除。房间成员关系与现有在线席位规则保持。
- 停用重复的 `berry-spark` 和 `honey-star` 旧装饰样式；旧持有和领取记录保留，不再新发放或装备。相关相册金币奖励继续按原规则结算。

## 发布边界

本版本更新程序和共享 Web 客户端，不执行后台内容发布，不替换玩家数据库，不新增数据库迁移。上线沿用双端口预热及兼容性检查，保留回退版本和旧客户端资源。

后台“提交到双端”发布全部已保存的相册、每日图、任务、成长和装饰配置及图片索引；不上传本版本程序、界面、特效或新图片文件。运营内容仍由管理员预览并确认提交。

共享源码位于 `jigsaw-nook-taptap`；本发布包使用它导出的客户端。微信安装包需按独立交付流程重新构建上传，本次 Web 发布不等于微信包发布。
