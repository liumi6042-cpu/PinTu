# Web 相册、任务与装饰界面

本轮仅本地接入和预览，没有上线，也没有修改后台已保存配置。

## 正式页面

- `/zh/albums`、`/albums`：统一尺寸的相册卡片，显示收藏进度、拥有状态和奖励摘要；详情提供画面列表及拼图片数选择。可用相册优先显示，空册标记“待上新”，隐藏价格、空进度与解锁按钮。相册里程碑达标由服务器自动发放，页面显示实际领取快照。历史已购画面独立展示，保持可开拼入口。
- `/zh/tasks`、`/tasks`：日常、好友、邀请分组，显示真实目标、进度、金币与经验；可领取任务与小礼物、复制邀请、发送与接受好友申请。任务不展示任何体力奖励。
- `/zh/decorations`、`/decorations`：使用房间同一份指针 SVG 图案，提供碎片兑换、使用与恢复默认。来源显示后台当前配置的实际相册名称和收藏门槛，点击可进入相应相册。没有覆盖旧庭院、孵蛋、签到和气泡/指针资产。

新增导航与账户等级、金币、装饰碎片仅在 `/api/player-content` 返回有效共享内容版本时展示；未启用时原大厅、图库、记录和房间继续可用。中文和英文页面地址成对，切换语言保留在对应页面。

客户端请求按身份共用缓存与在途请求，每 30 秒只在可见页面刷新。更改指针同时通知现有房间及跨标签样式监听。邀请链接绑定一次后移除邀请参数，保留其他参数与 hash。

存在尚未结算的拼图奖励时显示服务器的实际提示，禁用领取、金币购买和碎片兑换；可继续查看相册、选择画面和使用已有装饰。坏配置由接口返回不可用状态，不生成假成功提示或虚构余额。

## 独立交互预览

运行 `node prototypes/managed-content/server.mjs`，浏览器打开 `http://127.0.0.1:3833/`。说明位于 `prototypes/managed-content/README.md`。

本次真实 Web 本地入口为 `http://127.0.0.1:3334/zh/albums`，同端口可访问任务、装饰与大厅；独立样例中的“公开大厅”也指向该端口。

预览复用正式宽屏样式及已交付图片，顶部明确标记示例账号与数值。相册筛选、搜索、详情、示例金币解锁、选片、示例任务领取、碎片兑换、指针使用与相册奖励链接均可交互；只更改浏览器内存，不写账号、房间、CMS 配置或数据库。可随时重置。

当前定向验证：TypeScript 检查通过；独立预览两个脚本语法检查通过；本地页面、示例 JSON 和实际缩略图均返回 200。界面截图由协调会话统一验收和归档，不能把本地预览描述为线上已发布。

素材边界仍为 134 张已交付、53 张待交付；页面只使用本次服务器可用版本实际提供的图片，不虚构未交付素材或玩家收藏。
