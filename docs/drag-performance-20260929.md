# 拖动性能修复 — 2026-09-29

房间内拖动拼图时，之前在部分片数或放大倍率下会在每一帧重新裁剪原图、绘制阴影和拼块边缘，拼成大块后更容易出现掉帧和拖动延迟。

本次调整：

- 所有片数的拼图都预先建立拼块缓存。
- 拖动、画布平移和双指缩放期间优先复用缓存图块，避免重复裁剪。
- 松手后的静止画面仍保留原图绘制路径，以维持高倍率下的清晰度。
- 放下请求等待确认时允许立即再次拖动同一组拼块；请求仍按顺序提交，避免旧确认覆盖新位置。
