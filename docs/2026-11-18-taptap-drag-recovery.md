# TapTap v53.22 拼块卡住修复

玩家反馈放手后仍提示「请先放下当前拼块」，点别的拼块又提示「确认位置」，重新进房后还可能复发。本次以 TapTap v53.21 的 `bf040b9` 为基线，在 `codex/taptap-drag-recovery` 上修复两条可复现的路径。玩家设备上究竟发生哪一条，仍需真机验证。

- WebView 漏报抬手时，下次可识别的新触点会结束旧手势。拖动连续 15 秒无输入也会结束。移动过的拼块按最后有效位置提交，未移动则释放占用。浏览器输入层同时清理旧触点，恢复拼图工具的点击。
- 房间读取失败时会结束仍留在实时通道的持有状态。实时操作掉线后会读取服务器位置，首次读取失败会随房间轮询再尝试。普通房间可在同步后用 HTTP 接受新操作，实时通道恢复后使用新的序号，避免重发旧操作。
- TapTap 多人接口明确报告本机已加入的连接断开时显示「与 TapTap 的实时连接已断开，改用游戏服务器同步」。房间本身同步失败显示「房间同步中断，正在重连…」。
