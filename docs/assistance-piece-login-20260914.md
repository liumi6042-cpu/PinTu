# 拼图帮助与大片数登录

用户确认500片及以上需要登录普通账号，并要求更新不影响正在游玩的玩家。

原图按钮、浮层和新的原图授权已移除；保留历史reference记录以兼容存档与旧数据。底图上限从1增加到2，每次30秒；使用中再次请求不会消耗第二次，超时后才可再次开启。已用过一次的身份保留该记录，还可用一次。提示仍为3次、每次最多3片、30秒，不自动放置。

新开局与第一次加入500片及以上房间在服务器验证账号；请求体伪造身份不生效，普通账号无需会员。108/300片保持游客开局。已有owner/admitted/participants/members中的服务器身份可继续与重连；现有票据的读取、心跳、拖动、聊天没有新增门槛。旧高片数与历史散片不重新生成。

图库片数和大厅卡片说明登录要求。开局收到登录要求后跳转登录；白名单返回地址保留图片与片数，登录后仍需点击图片开始，避免自动产生多余房间。已有房间登录后返回该房间。帮助页、界面说明与英文搜索文案同步更新。

本次没有新增数据库迁移、图片、后台轮询或Canvas每帧操作。部署采用现有双端口预热、旧实例排空流程，保留旧静态资源，不要求正在玩的用户刷新。旧页面的按钮布局会在用户下次主动打开/刷新后更新。
