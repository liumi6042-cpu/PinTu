## 已接入行为

统一发布读取器一次固定完整版本，校验四份公开配置与可选资产清单；缺少发布指针保留原流程，损坏版本返回不可用。新增相册、任务、等级、金币、装饰碎片及指针与旧账号、房间、庭院、孵蛋、气泡和指针库存分开保存，没有自动折算或覆盖旧库存。旧房间继续加入、继续进度；新开图库房间校验当前相册权限，今日图不受付费相册限制。已购图片按购买快照保留使用权。

Web 无体力显示、消耗、恢复或奖励。金币与经验采用共用任务配置，缺失的旧 coins 按 0 读取；既有领取收据及礼包数值保持原快照。全零奖励明确显示暂无奖励，不显示虚构纪念品或空的小礼物。

奖励事件与房间成功 CAS 在同一事务入账。错误放置、仅拿起/移动、失败 CAS 不记奖励。待结算事件保存原时间、参与条件和当时有效的奖励快照；恢复时仍归原北京时间日期。原配置无法读取时明确排队，使用恢复后首次固定的有效发布版本，并保留该选择与提示，不冒充原版结算。重复、并发领取和恢复不重发。故障期间可继续拼图，领奖暂不可用。

相册卡片尺寸统一，有内容的相册前置；空册显示待上新、隐藏价格和空进度，不能购买。来源显示当前相册奖励配置。选择图片提供支持的片数选项，500 片及以上创建继续沿用普通账号登录要求。新指针同时应用于本人画布和同房间其他人的位置显示，原有静止指针保留规则未改。
