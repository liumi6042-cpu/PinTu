# 一起拼拼拼 Steam 发行与摩点众筹规划

日期：2026-10-21。阶段：可行性研究与候选方案，尚未批准开发或对外承诺。

《一起拼拼拼》可以规划为面向 PC 的买断制多人拼图游戏，采用无广告本体、可选主题 DLC、持续免费内容和国内游戏联机优化。摩点准入是当前最大的外部不确定性：已有 Web 运营与 TapTap 测试必须披露，改名、换 UI 和 Logo 不能证明首发资格重新计算。

## 用户已明确的方向

| 项目 | 当前意向 |
| --- | --- |
| 游戏名称 | 一起拼拼拼 |
| 发行渠道 | Steam，计划通过摩点众筹支持 PC 版交付和运营 |
| 本体价格 | 目标人民币 19.9 元，最终以 Steamworks 可提交价格为准 |
| Steam 商业模式 | 完全无广告 |
| 当前服务器费用 | 用户提供约 150 元/月 |
| 未来服务器预算 | 用户预估约 1,000 元/月，尚非容量测算或已购买套餐 |
| 众筹回报 | 本体 Steam Key、众筹指针装饰，高档增加 DLC 图包 |
| 内容方向 | 希望长期每天至少更新一张全新免费拼图，承诺期限待评估 |

下文的档位价格、免费图保留方式、离线模式、联机保障期限、视觉方向和筹资目标均是建议，不能视为用户已经批准。

## 摩点资格与发行时序

[摩点项目规范](https://www.modian.com/protocal/2/2)第 6 条使用“公众面前首次亮相”的表述，同时提及大陆其他相似销售平台；第 9 条又要求提供 Demo。公开免费测试是否影响本项目资格，没有可以直接套用的明确结论。

[发起者协议](https://www.modian.com/protocal/3/2)当前版本为 2026-09-03。其首发销售、跨渠道保价、平台标识和摩点专属回报条款，会影响 Steam 发售、首发折扣和混合档位。尤其是众筹期间至全部回报发货后 90 天的价格比较，不能自行解释为只比较本体价格。平台需明确包含本体、装饰和 DLC 的档位如何计算。

项目历史不能只说明 TapTap 免费测试：本地材料记载原 Web 已面向公众运行，TapTap 曾使用“一起拼拼拼”，后来更名“拼图小窝”。此前设计过广告、会员和金币图包；哪些实际开放、哪些产生真实收入，需要依据记录清点，金币购图本身不能证明发生现金交易。

建议准备一页事实材料，向摩点申请书面预判，包含以下问题：

1. 提供 Web 链接、TapTap 页面、各阶段名称、开放时间、测试范围，以及实际收费或广告收入情况，确认是否接受该同源项目的 PC 买断版本。
2. PC 版新增桌面交互、独立安装、Steam 身份、无广告商业模式和本地单人功能，哪些差异能支持立项？
3. 是否允许 Steam 先公开 Coming Soon 页面、暂不销售，然后摩点先众筹、众筹结束后在约定日期 Steam 发售？
4. 基础 Key、限定装饰与普通 DLC 混合档的保价如何比较？Steam 首发折扣能否进行、何时进行？
5. 是否允许 Steam 标识、商店链接及 Steam Key 作为交付方式？摩点限定装饰经 Steam 交付给支持者应如何处理？
6. 免费日更、联机服务如何填写承诺期限？它们是否影响“全部回报发货”的认定，以及尾款和保价期起算？
7. 游戏类 6% 服务费和分期结算是否适用于本项目，有无另行约定？

筹资目标应围绕“完成 PC 买断版及明确范围的内容和联机体验”，服务器列入用途。单纯为现有网页续服务器，不足以清楚呈现要交付的创造项目。

如果摩点不接受该项目的既往公开历史，应调整筹资渠道或采取正常 Steam 发行；不通过继续改名来宣称全新首发。无需为了本次咨询擅自关闭 TapTap 测试或撤下旧版。

## PC 版产品与视觉范围

建议定位为“可以独自慢慢拼，也能与朋友一起完成的轻松拼图桌游”。19.9 元本体应有完整体验；DLC 提供额外主题，不承担补齐基础功能的任务。

### 桌面界面

| 页面 | PC 版建议 |
| --- | --- |
| 大厅 | 突出继续拼图、今日新图、与朋友同玩；图片直接可选，尽量 1—2 次操作开局 |
| 拼图桌面 | 拼图占据主要视口，工具、参考图、成员、聊天按需展开，避免常驻大侧栏 |
| 图库与收藏 | 清晰区分本体内容、免费日更、已购 DLC、未拥有 DLC；保留稳定图片 ID 和完成记录 |
| 装饰 | 明确区分众筹限定、普通可获得；指针不能影响拼合结果或其他玩家的判断 |
| 设置 | 窗口与全屏、音量、UI 缩放、操作说明、本地存档和联网状态 |

现有共用客户端已经有滚轮缩放、中键或空格平移、Esc 收起浮层等桌面基础。首轮应在此基础上改版，而不是另写一套拼图引擎。Windows 版先完成；Steam Deck、完整手柄支持、其他系统作为后续候选，未确认前不写进首发卖点。

商业规则需要同步调整：无广告不只是隐藏广告按钮，提示、底图、建房和奖励不能继续依赖观看广告或强制分享。建议 Steam 版取消体力限制，付费图包直接对应 Steam DLC 权益，普通成长和装饰收集保留有意义的部分。[Steam 广告规则](https://partner.steamgames.com/doc/marketing/advertising)明确不支持以观看广告解锁游玩或发奖的商业链路。

### 品牌与素材

建议先确认一条 PC 视觉方向，再制作全套素材：柔和桌面质感、清楚的拼块轮廓与协作指针，强调一起完成的动作。Logo 以“一起拼拼拼”的可读性为主，用三个“拼”的节奏和拼合关系建立识别；不把标题堆成难读的小方块。

先做大厅、拼图、图包详情三张关键画面，以及一组 Logo 与主宣传图。视觉获认可后，再扩成全套。宣传图可以创作，商店游戏截图必须来自实际 PC 版；现有 TapTap 截图不能冒充尚未完成的 PC 新界面。

按当前 [Steam 商店素材规格](https://partner.steamgames.com/doc/store/assets/standard)和[游戏库规格](https://partner.steamgames.com/doc/store/assets/libraryassets)制作：

| 素材 | 像素尺寸 |
| --- | --- |
| 商店 Header | 920 × 430 |
| Small Capsule | 462 × 174 |
| Main Capsule | 1232 × 706 |
| Vertical Capsule | 748 × 896 |
| 游戏库 Capsule | 600 × 900 |
| 游戏库 Header | 920 × 430 |
| 游戏库 Hero | 3840 × 1240，无文字 |
| 透明 Logo | 宽 1280 和／或高 720，按比例 |
| 实机截图 | 至少 5 张，最低 1920 × 1080，16:9 |

普通胶囊图不加入众筹、价格、日更、无广告等营销文案；参照[素材规则](https://partner.steamgames.com/doc/store/assets/rules)。现有 460 × 215 的旧素材不能直接当作当前 Header 成品。

实际交付给玩家的 AI 辅助生成图片，应在 [Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)如实申报，并保留商业使用授权及来源。名称检索与商标冲突仍需在品牌定稿前核对。

## 众筹回报候选

建议先控制在三个数字回报档，避免实物物流和无限内容承诺。以下价格与数量仅用于讨论，须结合摩点保价答复和制作预算定稿。

| 候选档 | 回报 |
| --- | --- |
| 19.9 元基础支持 | 本体 Steam Key × 1，众筹指针装饰包 × 1 |
| 29.9 元主题支持 | 基础档全部内容，指定主题 DLC 图包 × 1 |
| 49.9 元收藏支持 | 基础档全部内容，指定主题 DLC 图包共 3 包 |

每包可以先按 10—12 张不同画作评估成本，正式上线众筹前固定主题、张数和交付日期。高档获得固定内容，不承诺“所有未来 DLC”。这三个候选档不是对 Steam 商店的最终定价，也不代表平台已认可差价安排。

本体 Key 与 DLC 均按正式发行产品交付，DLC 不能代替本体。限定指针只做视觉差异；普通拼图关卡 DLC 后续也在 Steam 正常销售，避免把可玩内容误当作纯装饰例外。

DLC 联机权益需在销售前明确。建议评估“所有参与者都拥有本体，房主拥有图包即可邀请朋友加入”，降低朋友一起玩的门槛；加入房间不授予整包所有权。另一方案是每位参与者均需拥有 DLC。二者尚未决定，入房校验、图片访问和众筹说明必须使用同一规则。

[Steam Key 规则](https://partner.steamgames.com/doc/features/keys)允许限时众筹回报，当前最长 30 天；宣传前需完成入驻并持有该产品的 App credit 或 AppID。建议使用正式发行 Key，提前激活不提前解锁。数量须先获批，5,000 个并非保证。纯装饰众筹 DLC 有例外，测试 Key 不作为付费本体交付。

交付系统应记录订单与 Key 分配、DLC 权益和装饰领取结果，重复领取不能多发；绑定真实 Steam 身份，不以昵称匹配。Key 不写入公开文档、截图或客户端包。退款、取消订单按有效记录处理，不能误停其他支持者的权益。

## 日更承诺与持续运营

用户希望长期日更，期限仍待评估，本稿不把它改写成已确认的一年承诺。

现有机制是“当天排期 → 尚未首发的新图候选 → 已有相册随机推荐”。它能维持每日入口，但候选用尽会重复旧图，而且首发结束后可以归入收费相册。这不等于“每天新增一张，且以后一直免费”。

建议在正式承诺前明确以下口径：

- 新图：此前未在 Steam 版发布过的不同画作；换裁切、换难度和轮换旧图不计新增。
- 免费：建议对所有本体玩家持续开放，而非仅当天免费、次日转为付费。每日免费库与付费 DLC 成员分开管理。
- 时间：采用北京时间的固定发布时间；一天至少一张与全年累计 365 张是两种不同承诺，不能相互替代。
- 期限：长期日更作为运营目标，另外评估一段明确的最低保障期，例如首发后 12 个月；这只是待选方案。
- 联机：独立于图片更新承诺，明确服务范围、保障期限和维护安排，不能把永久联机隐含在一次买断中。

内容流水线建议为：批量制作 → 授权与画面筛选 → 拼图适配 → 压缩及缩略图 → 人工批准入池 → 定时发布 → 发布失败补偿与记录。提前准备 30—60 张合格储备，储备低于 30 天提示补充；图片已生成不等于已审核、已上传或已发布。

正式预算至少覆盖 365 张/年的画作制作、筛选与返工，以及程序维护。按每张实际综合现金成本 c 元计算，一年新图现金需求为 365c，人工时间另计。众筹无法单独支撑无限期限义务，长期运营应由后续本体和 DLC 收入共同承担。

需与摩点确认持续内容、服务承诺怎样履约和结算，不能未经认可把仍欠交付的内容宣布为“全部发货”。

## 国内网络与降本

Steam 发行允许保留自有联网服务。推荐把国内优化对象限定为本游戏的数据：身份交换、房间发现、拼块同步、指针、聊天和图片。Steam 客户端登录、商店、社区和官方好友服务并不会因为我们租服务器而整体提速。

建议架构：

```text
Steam PC 客户端
  ├─ 本地基础图与已交付 DLC、本地单人拼图和存档
  ├─ Steam 认证票据 → 自有安全后端 → 官方认证接口
  ├─ 房间码／好友邀请 → 游戏 API 与 WSS → 房间权威服务
  └─ 免费新增图目录 → 静态资源分发 → 本地缓存
```

基础图和 DLC 尽量随 Steam 安装与更新分发，单人模式本地运行，联网才占用房间服务。新图采用本地缓存和增量下载，不在每次进房重复下载整幅图。多人消息只发送变化；光标和拖动预览与正式落片分开处理，长期存档使用合并写入和休眠恢复，保留既有进度。

中国玩家可优先使用国内游戏节点；国内外朋友仍需进入同一个权威房间，不能按玩家地区拆成两份状态。首期优先优化现有后端，是否增加国内完整房间服务、只设接入点或海外节点，应由线路与并发测量决定。转发服务器不能自动增加数据库和权威服务容量，也可能增加绕路。

Steam 身份采用[官方票据认证](https://partner.steamgames.com/doc/features/auth)，后端按[Web API 文档](https://partner.steamgames.com/doc/webapi_overview)安全调用官方接口；发行商密钥只留后端。客户端自报 SteamID、已购 DLC 或地区都不能作为可信权限。Steam 身份与旧 Web/TapTap 数据的绑定另设规则，不自动合并同名用户。

现有 WSS 不能直接套用 [Steam Datagram Relay](https://partner.steamgames.com/doc/features/multiplayer/steamdatagramrelay)。初版不为降本直接重写 P2P，避免引入房主离开、状态迁移与持久房恢复等额外工作。

国内线路技术可行性和具体大陆部署条件需分别核实。国际 Steam 与[蒸汽平台](https://partner.steamgames.com/doc/store/china)是不同发行路径；蒸汽平台要求游戏审批。不能把 Steam 上架或域名备案当作所有大陆运营要求已经满足。

本地已有网络诊断的 2026-10-20 小样本更指向公网链路，未发现 CPU 或内存打满；这不是当前容量结论。1,000 元/月先作为预算情景，不据此预购机器或承诺同时在线人数。后续重点测每玩家小时流量、每次落片成本、在线房间量及真实入房耗时。

## 资金测算

以下仅针对摩点订单，按当前游戏类 6% 服务费情景估算，具体费率以项目约定为准；未计税费、退款、内容制作、人工、适配、Steam 产品费用、额外 CDN 与备份费用。未来 1,000 元/月应再核对是否已含带宽、请求费和全部节点，防止漏项或重复计费。

| 项目 | 粗算 |
| --- | ---: |
| 当前服务器年成本，150 元/月 | 1,800 元 |
| 未来服务器年预算，1,000 元/月 | 12,000 元 |
| 19.9 元基础档扣 6% 后 | 18.706 元/份 |
| 只覆盖未来一年服务器所需 | 642 份基础档，众筹额 12,775.80 元 |
| 众筹 20,000 元，扣服务费后 | 18,800 元；扣一年服务器后余 6,800 元 |
| 众筹 30,000 元，扣服务费后 | 28,200 元；扣一年服务器后余 16,200 元 |

2—3 万元可以作为讨论筹资目标的区间；只有把适配、素材、每日新图、交付、税费和预备金列清，才能确定最低目标。上述余额不能直接称为利润。

[摩点结算规则](https://www.modian.com/protocal/3/5)当前游戏类费率为 6% 或另行确认，扣费后按 50%／30%／20% 分期结算。2 万元情景首期约 9,400 元，3 万元情景约 14,100 元，并非众筹结束立即全额可用。成功项目后续退款仍可能产生服务费成本，需要自有周转资金。

这张表不能套用于 Steam 商店自然销量。后续 Steam 净收入按实际价格、折扣、退款、税费及合同结算单独计算，不把摩点和 Steam 两种订单混算。

## 建议推进顺序

| 阶段 | 交付结果 | 进入下一步的条件 |
| --- | --- | --- |
| 一 资格与预算 | 摩点历史披露材料、书面准入及价格答复；本体/DLC/免费图边界与预算 | 准入和销售时序可执行 |
| 二 PC 体验与品牌 | 三个关键页面、Logo 与主图方向、Windows 本地可玩包 | 视觉与核心 PC 体验确认 |
| 三 Steam 与服务 | Steam 身份、DLC 权益、本地单人存档、联网服务和众筹发奖 | 关键权益与存档正确，实际网络表现可接受 |
| 四 发行准备 | 商店真实素材、内容申报、已批准 Key 数量、日更储备、完整众筹页 | Steam/Mo 平台条件和现金周转均满足 |
| 五 众筹与交付 | 最长 30 天的限时众筹，按约定日期发行并交付 | 实际发货记录和运营台账 |

可在第一阶段同时做内部 PC 样稿，但不要先投入全套物料再赌摩点准入。众筹前应已有可供平台检查的版本，宣传重点是实际 PC 体验。

Steam 首作当前还涉及产品费后 21 天等待、Coming Soon 至少两周，以及 AppID 创建后三周方可申请首作 Key；审核时间另留余量。这些条件可部分并行，最终依[入驻流程](https://partner.steamgames.com/doc/gettingstarted/onboarding)、[Key 规则](https://partner.steamgames.com/doc/features/keys)和实际后台状态排期，不能承诺一个未经核对的发售日期。

首轮验证集中于真正新增的行为：启动与 Steam 身份、离线存档、两名玩家入房和重连、DLC 归属、装饰发放幂等，以及免费新图不收费不重复。视觉看关键页面即可，不反复执行无关全量回归。
