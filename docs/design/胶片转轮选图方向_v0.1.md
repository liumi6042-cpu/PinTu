# 胶片转轮选图方向

日期：2026年9月7日  
状态：交互方向评审中

## 用户最新方向

此前生成的首页图片不再作为设计依据。新的选图方式参考用户提供的环形胶片截图：让拼图图片沿立体弧面排列，通过转动浏览，并在上下安排搜索及分类。

## 当前交互预览

- 上方为搜索框，中间为可转动的胶片，下方为分类和当前图片的选择按钮。
- 滚轮、左右拖动、方向键和左右按钮均可切换图片；点击侧面图片可将其转到正面。
- 停止滚动或拖动后，胶片停靠到最近的一张图片。标题、片数、序号与当前图片同步。
- 搜索按名称、分类和片数筛选，分类与搜索可以组合使用。
- 零结果显示清空入口，一至两张结果使用清楚的平面选择展示，三张及以上呈环形浏览。
- 默认采用参考图的深色氛围；预览提供背景深浅、倾斜程度及胶片齿孔的设计调整项。
- 动效由用户操作触发，不持续自动转动；减少动态效果的系统偏好会关闭插值过渡。

预览只覆盖选图交互。封面、分类和片数为示例内容，点击选择会在当前预览中记录选择，不会启动真实拼图或创建多人房间。

## 后续待细化

需根据本轮体验确认胶片的弧度、倾斜、转动速度、背景和分类位置，再补齐实际图库以及片数设置、单人和好友入口。广告位置也需要按新的整体布局重新讨论。

## 验证记录

已在1024、736与360像素内容宽度下检查布局，并操作验证滚轮、拖动、方向键、首尾衔接、侧面图片点击、分类、单一搜索结果、空结果及确认选图。未验证真实游戏、存档或多人同步。
