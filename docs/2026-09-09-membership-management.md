# 会员权益、状态与自建房间管理

## 交付范围

- `/membership` 展示免费/会员权益、房间数量和人数、到期规则，并明确订阅购买尚未开放。首页与社区导航新增会员入口。
- `/membership/manage` 展示服务器中的会员状态、起止时间、到期不续费状态、实际订单记录和当前身份创建的多人房间。游客可以查看旧游客房间，登录只用于读取账号会员；登录后返回会员管理。
- 房主可以修改名称（1–40 个字符）、公开/仅邀请、是否接待新玩家，复制局域网邀请链接并继续拼图。局域网 HTTP 无剪贴板接口时显示可手动复制的链接。
- 暂停接待只限制新访客，已入座的朋友、房主可以回来；旧游客之后选择登录仍可凭原游客身份恢复入场资格。
- 有效账号会员最多同时保留 3 个未完成、未过期的自建多人房间，每桌最多 8 人。已有完成或过期房间不占创建名额。
- 会员到期后不能新建，已有房间仍可游玩、管理，沿用实际游玩后 30 天、完成后 30 天的保留规则。修改设置不延长保留时间，不改拼块、计时或成绩；成就继续保留。

没有选择套餐价格、接入支付或开放购买，没有自动扣款、前端测试会员开关或公开授予会员接口。头像框、桌布等只标注为后续计划。订单区只读取真实订单，没有示例付款记录。

## 服务端保证

新增迁移 `0004_memberships.sql` 保存账号权益与订单，既有迁移没有改写。更新前已把本地数据库一致性备份到 `work/backups/before-membership-management-20260909`。

创建接口验证服务器权益，`isMember` 等客户端字段不能授权。权益、名额计数、房间写入及目录写入在同一次 D1 事务中完成，防止并发超过上限。预约到期不续费不提前撤销当期权益。

管理接口通过验证过的账号/游客身份检查房主，只接受名称、可见范围和接待开关。房间 JSON 和大厅目录原子更新，避免改为私人后仍出现在公开列表。旧房间及匿名票据兼容继续保留。

RoomClient 只在必要元数据变动时通知界面，包含房名、接待状态、完成与成就日期；拼块位置增量仍走原 Canvas 通道。
