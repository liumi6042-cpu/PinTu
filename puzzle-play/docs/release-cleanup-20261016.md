# 发布构建临时目录

发布命令把构建、打包及验证放进同一清理生命周期，只回收这次调用用 `mkdtemp` 创建的目录。旧构建目录、历史 staging、运行包和日志不在自动清理范围；目录联接及被替换的输出路径会拒绝清理。

子构建使用相同机制清理它本次创建的隔离源码目录，依赖目录联接继续先解除，正式依赖和源文件不受影响。

每个目录独立清理并复查是否残留，结果保存到 `work/release-cleanup/<本次标识>.json`。即使构建提前失败也保留错误信息并回收本次输出。清理失败或无声残留会返回非零状态，`latest.json` 不会被标为最终 `verified=true`；已经生成的包和日志继续保留供排查。

本机 Node 24.13.0 的同步递归删除在中文目录下曾返回成功但未删除；这里使用标准异步 `fs.rm`、等待完成后再检查，不更改全局 Node。

验证只运行 `node --test tests/release-cleanup.test.mjs` 的小型夹具，不重新构建运行包，也不清理已有历史目录。此变更仅影响本地发布工具，无需重新部署线上应用。
