# Room chat delivery

Implemented room-scoped text chat for seated guests and accounts, including
existing private multiplayer rooms. Solo rooms and a global lobby chat are
excluded. The right-hand button opens an independent nonmodal panel. Unread
messages, local per-room blocking and reset, Unicode text, IME-safe Enter,
Shift+Enter line breaks, retryable drafts, English/Chinese copy and both table
themes are supported. No notification audio or automatic opening.

The message history is separate from the puzzle state. Migration 0011 adds a
bounded indexed table and deletion cascade. POST admission and limits are atomic;
author information comes from authenticated membership. Messages are plain text,
up to 300 Unicode code points; each identity may send once every two seconds and
at most 20 times per minute. Retain the latest 100 messages per room. Idempotent
request IDs prevent duplicate recent messages on uncertain retries. GET is
authenticated, incremental, no-store and noindex. Poll every 2.5 seconds open or
12 seconds closed, pause while hidden, and respect retry delays. Chat state
updates neither the parent game nor its Canvas engine.
