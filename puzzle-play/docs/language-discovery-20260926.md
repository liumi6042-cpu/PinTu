## 自动语言

本次检查的 IP 接口返回英文；旧逻辑还存在检测结果未同步成对页面地址的问题，导致检测状态与实际页面语言不一致。IP 结果不代表用户的实际所在地，可能受代理出口影响。

用户确认：中文浏览器即使使用海外代理也优先中文。手动语言优先；Auto 下浏览器首选支持语言为中文或可信 IP 判断为中文地区即显示中文。其他情况保留英文或浏览器兜底。API 仍如实返回 IP 判断，组合决策在客户端完成。

检测完成后同步公开页面的中英文成对地址，保留 query/hash；房间等非成对页不跳转。检测结果使用偏好 revision 防止迟到结果覆盖手动选择。Auto 按钮不再发起第二个独立检测请求。

## 画中发现

根据目标区域和当前拼块组位置绘制暖光椭圆圈、四个小光点和附近文字，持续约 4.8 秒。高亮跟随缩放、平移和拼块组移动；并非逐像素轮廓描边。不拦截鼠标，不中断拼图；减少动态效果偏好使用静态提示。仅活动提示期间运行位置更新。
