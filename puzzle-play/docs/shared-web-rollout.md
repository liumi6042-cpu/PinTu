## 玩家数据保护

- 原账号优先，已有持久游客凭证原样恢复。首次游客先持久保存身份再连接；不能把一个新 H5 游客身份当成原 Web 用户。
- 历史 v1/v2 房间使用原散片和桌面范围。新共享房间使用标记 v3 的新间距，完整权威坐标从服务端返回；旧房间不重建种子。
- 礼包沿用原礼包 ID 与已生成的数值快照；重复或并发开启不会改领下一份礼包。重复购买已购相册不重复扣款，保留被调整相册中的既有图片权益。
- 不自动合并旧游客与账号、不迁移已有仅 Cookie 的历史游客钱包。原游客若失去全部恢复凭证，不能承诺可找回。
- 房间凭证绑定当前账号或游客身份。登录、换号或退出后重新确认房间成员，避免把新奖励计入前一个身份；停止接纳新成员且只有旧游客具备入场权限的历史房间，明确引导原版继续。
- 建房请求重试沿用原 Web 行为，尚未新增建房幂等收据；奖励领取与结算仍有原幂等保护。
