# 免费上传与每局帮助

2026-09-13 用户规则：普通账号登录后可上传最多 10 张私人图片，并免费创建自上传单人局。私人房间仍需有效会员，最多 3 个进行中的私人房间。图片大小、格式、隐私、删除保护和既有进度规则不变。

每局每位玩家原图、底图各一次，各 30 秒。提示最多三次，每次选择最多三片未归位、未被其他玩家持有的拼块，标注相同编号的拼块和目标轮廓，显示 30 秒，不自动移动。剩余不足三片时提示剩余片数，没有可提示拼块时不扣次数。相同种类在显示期间重复请求不扣次数，也不延长时间。

服务器通过 0010 迁移记录房间、已验证账号/游客身份和请求 ID。额度检查与写入使用同一 SQL 语句；刷新、重新加入、重试不重置次数。记录不进入房间同步，不修改拼块、计时、贡献或版本。记录随过期房间删除级联清理。旧局首次使用新功能时获得完整额度。

本机游戏按图片、网格和种子保存额度；重开新局得到新额度。支持 Web Locks 的浏览器序列化多标签点击。清理浏览器数据会清理本机记录；本机额度不作为服务器权益依据。服务器玩家更换身份不自动合并额度，与现有游客记录规则一致。

界面显示剩余次数及倒计时。原图沿用游玩原图并按网格等比裁切，底图使用 Canvas 已裁切图片；三片提示不移动镜头。倒计时只更新工具组件，Canvas 仅在启用、到期和现有交互时重绘，不创建持续动画。

验证：TypeScript、25 项相关单元回归通过；独立本地 SQLite + 实际 Node HTTP 验证普通账号上传/开局、隐私和配额竞争、会员私人房间限制、每位玩家次数、重入、幂等及状态不变。内置浏览器拦截本地地址，目视验收随上线检查记录在 work 中。
